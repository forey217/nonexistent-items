## 游戏内容与操作

观察局接待大厅、星系仪世界封存室，以及两关完整解谜与归档回程。第一关“新手校准室”使用冰晶、重力、倒悬；第二关“纸山叠影”上下层独立四规则，包含显影旧廊、留影夹、山水镇纸、踏板、水闸、吊台和双锚。

| 输入 | 功能 |
| --- | --- |
| WASD / 方向键 | 人物移动；第二关走入楼梯自动上下楼 |
| 左键地面 | 点击寻路 |
| 右键镇纸 | 第一关互动；第二关选择方向后推动 |
| 1 / 2 / 3 | 切换规则；第二关另有4显影，作用于选中的操作层 |
| H | 查看提示或观测记录 |
| M / F11 | 静音 / 全屏 |
| F10 | 按游戏流程返回启动界面 |

第二关右上角“观测仪表 → 演示 → 第二关完整演示”提供真实寻路和机关驱动的完整路线，支持暂停、继续、退出与再次演示；演示结束可回到原进度，不覆盖玩家存档和解锁记录。第二关需先正常通关第一关解锁。
