# 第二关任务完成盖章 v0.56.0

基于已发布的 v0.55.0 验收快照，仅增加第二关任务栏反馈，第一关沿用原样。本版不包含工作区同期尚未发布的其他功能。

- 使用真实事实边沿：取得夹子、升起并固定接物台、山纹实际落稳、载货吊台实际到达上层、上锚、双锚、归档触发。文字变化、世界切换和checkpoint数值变化本身不完成任务；空吊台不完成运输任务。
- 原任务与编号保留，0.20秒展开并落印，显示绘制勾号、真实宋体“校准完成”与切角双线档案章；金边仅亮一次。印章完整出现后停留1.20秒，再用0.15秒淡出旧页、0.15秒淡入新页，显示“下一步”约1秒。无新增音效、场景光效或镜头运动。
- 不同任务可自适应多行高度，印章单独占底部一行；固定左上角位置。面板及所有新增内容穿透鼠标，不再截获地图点击。完整观测记录与H提示继续保留。
- 最多7个不同事实事件排队，每个只播放一次。读档和重新开始清空队列并建立事实基线，不改存档格式。暂停冻结年龄，低动态选项取消位移缩放；最终任务保持完成状态并沿原流程归档，不等待UI动画阻塞通关。
- 既有机关共鸣保留，旧任务回执接口只作兼容，不重复驱动新任务栏。任务完成后短暂停留是显示层行为，游戏判定、完整记录、导航与交互始终使用真实进度。

专项测试覆盖实际下落、完整停留、编号切换、长任务、快速连续完成、鼠标穿透、暂停、读档、重开、低动态与两种窗口尺寸；另外进行完整通关、机关共鸣和双关HUD回归。真实引擎运行视频展示镇纸下落、任务盖章及下一步展开。
