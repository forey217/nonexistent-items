# 逐句角色配音 v01

按用户确认的《配音制作-v01》提示词与74句清单生成并接入；不改动对白正文，不包含第二关对白。

衍月固定使用晓伊女声（zh-CN-XiaoyiNeural，语速+3%，音调+2Hz），共16句。特斯拉按用户选定的第一版试听更换为云扬男声（zh-CN-YunyangNeural，语速-8%，音调-4Hz），共58句，逐句重新合成并重新计算词时间；服务当前音色列表中的Female/Male字段已核对。

每句独立MP3，以角色加准确文本的SHA256固定编号绑定。实际音频位于assets/audio/dialogue_v01，manifest保留准确字幕、实际合成文本、音色、参数、时长、校验值和词时间。数字按键使用中文数字、01号展开为零一号，字幕及编号依据仍保持原文。总时长以当前manifest逐句统计为准。

服务原生MP3经首尾静音裁切、响度匹配后输出单声道24kHz MP3；未宣称为无损母带。每句解码检查、校验值、峰值、时长、返回词文本及角色设置均核对。男女分开的完整审听串位于工作区“游戏策划/配音制作-v01/生成交付”；全部文件保留人工听感审听待确认标记。

运行时由dialogue_voice.gd只播放一条当前对白，speaker、准确文字或音色不符则不播放；缺少文件保留字幕。切句、跳过、读档或切场景通过原有clear流程停止旧声音。关内字幕至少覆盖完整音频及0.25秒余量，状态推进仍会清除过期提示。

声音路由至现有Dialogue总线，服从“对话语音”滑竿与M总静音，不串入音效或背景音通道。讲话时背景音乐临时降低6dB，停止后恢复。

镇纸首次展示、世界重叠示意，以及“先定星位，再压月痕，最后封界缝”高亮使用合成服务返回的词起始时间。词级时间用于对应口播，不声称是人工逐音素标注。阅读时提前点亮全文不会提前触发物品展示；跳过直接清理展示和音频。玩家快速切换目标不会积压旧语音。

自动化验证：`--voice-check`核对全部74个资源、男女绑定、文本一致、切句清理、关键字同步、字幕时长、音量和静音。既有加速玩法/对白检查默认不播放语音，保持其原有时序；配音专项使用真实语音及独立报告。

云扬替换版导出到builds/角色逐句配音-v03/世界不按说明书.exe；运行包附自动检查报告与音频来源说明。
