# 纸山叠影：滑轨与水车吊台修复 v01

修正山纹镇纸跨层运输后的轨道归属，并让水车吊台独立于任务阶段和载货状态运行。试玩程序：`builds/纸山叠影-吊台修复-v01/世界不按说明书.exe`。

## 滑行期间切换限制

任一镇纸处于滑轨运输状态时，两层的世界切换都会锁住。HUD按钮禁用，数字键与直接调用也在状态层拒绝；到达下一个真实止挡后自动解锁，不消耗额外冷却。观察上下层、走动和菜单不受这项限制影响。

山纹镇纸在吊台上静止时由吊台承载，抵达上层后归属上层导轨，只能连接上层中转台；从吊台离开后使用自身所在层的高度，不再继续跟随吊台。吊台未与当前层停靠时无法装卸镇纸。旧存档若记录吊台已到顶而山纹仍标记为下层，读取时修正该归属。

## 水车与乘台

水纹镇纸压住水闸踏板、水车开始工作时，吊台就升起，空载和任务前期也一样；停止供能后回落。水车转动、闸门位置与吊台驱动使用同一实际状态。空台升起不会冒记山纹运输完成，也不会推进任务。

吊台停靠后可以走上台面。升降期间人物脚底、阴影与相机高度跟随吊台，水平移动暂时锁定，避免跨出空井；停靠上层或下层时同步切换人物所属层、观察层及寻路区域，恢复行走。空井在吊台离开后禁止走入，平台停靠时才开放。

升降过程中临时剖开上层场景，避免地板遮住人物。中途菜单仍暂停机关；自动存档保留上一次安全状态，避免恢复到半空。
