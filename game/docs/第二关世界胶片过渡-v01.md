# 纸山叠影 · 双层世界胶片过渡

在 v0.51.0 完整演示整合基础上补齐第二关世界切换画面。视觉沿用第一关“透明胶片错位，再重新重合”：旧环境轻微反向错开，新环境从斜向半透明进入，约 0.22 秒完成对齐，约 0.55 秒恢复单一清晰画面。冰晶、重力、倒悬、显影继续使用当前场景配色。

## 保留的真实规则

第二关规则原本在 `state.switch_world` 成功时立即提交，本次仍在同一位置提交一次；没有移用第一关 0.22 秒的规则提交时刻。1.5 秒共享冷却、滑行禁切、旧廊与木桥站位保护、夹具固定、轨道接驳及双锚条件保留。失败请求不会启动动效。物理、任务、碰撞和导航不依赖画面动画。

## 渲染与双层隔离

新增 `paper_world_film.gd` 和 `paper_world_film.gdshader`。两个临时更新的环境视图共享现有 World3D、光照、相机及实时机关；只为目标楼层的静态环境建立并缓存渲染网格，不复制场景脚本、物理或任务逻辑。

| 内容 | 过渡处理 |
| --- | --- |
| 目标层石材、建筑、轨道、木桥与旧廊 | 新旧视觉层沿当前相机对应的斜方向错位，逐渐对齐 |
| 另一层与远景 | 两个环境视图共用同一份实时几何和材质，保持原规则 |
| 镇纸、吊台、水车、踏板、夹具等主要动态机关 | 单份实时状态，同一相机，不参与错位 |
| 衍月 | 从原主视图保留实际深度遮挡后的实时轮廓，按实际分辨率、姿态与相机投影生成遮罩 |
| HUD、字幕、名称 | 保留原界面，不参与胶片合成 |
| 脚下折叠环 | 复用第一关绘制，降低至 55% 强度；第四种显影使用灰绿色，人物遮罩避免光环盖住鞋脚 |

固定木桥在两份视觉中保持；未固定木桥和旧廊分别读取新旧规则显示。显影生活遗物保留原有渐显与余影。所有世界始终只有一份机关运动、通关条件与配音触发。

结束、重置、恢复时关闭两个额外视图并清除合成材质，隐藏缓存网格。相机、视口尺寸每帧同步；没有写死为 1280×800。缓存网格、世界材质与两个视图重复使用，空闲时不持续多渲染两张环境画面。

## 暂停与完整演示

普通菜单打开后冻结过渡和纸坊画面动作，额外视图停止更新。完整演示暂停仍冻结整个临时关卡；中途退出可恢复原关卡正在进行的胶片过渡，不用稳定检查点替代现场。

演示经过同一正式切换入口，等待胶片结束后再推进。画面计时独立于模拟倍率，正常约 0.55 秒；首次着色器编译或卡顿不会一次跳过整个动画。普通赶路约 2.3 倍，关键下落、升降、桥固定和双锚观察段保持原先较慢节奏。声音保留原音高，机械落定与折叠音进入原音效通道。

## 验证入口

专项 `--paper-film-check` 覆盖上下两层四种规则的 24 种有向切换、主视图人物像素比对、新旧环境差异、另一层隔离渲染比对、三种旋转、两种缩放、小窗口/宽屏/全屏、夹具与桥、真实吊台运动、滑行拒绝、暂停恢复、资源复用、演示退出恢复原过渡。

最终 Windows 程序的专项截图、报告及完整演示计时位于 `showcase/checks/integration-v0520/`。最终验收数量、计时及 SHA-256 随导出包提供；不修改旧版封存程序。
