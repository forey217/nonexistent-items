# 第二关轨道转角整合 v0.49.0

快照：20261023-02。以已验收的 v0.48.0 整合版为基础，只加入轨道视觉修整，保留旧版程序。

## 实装内容

- 下层水轨的笼口、接物踏板、水闸转角、导向弯；下层山轨吊台前转角；上层锚座前转角，均使用连续内外双轨与精确斜接面。
- 真实分支使用连续肩部接头；木枕、旧铜侧连接片与铆钉提供支撑。保留原有停靠十字刻线。
- 轨道直接依据原有三组连接表绘制，删除原先误连水轨与落料点的一段装饰轨。两条独立路线的平面交叉使用嵌合开槽，不产生额外逻辑分支或共面闪烁。
- 显影桥中段双轨跟随桥体显隐；吊台自身携带轨条，短接驳片仅在到站时伸出。固定轨道在井沿终止，吊台离开后不悬空。
- 双轨中心间距 0.54，轨条宽 0.065；顶面 0.1825，与镇纸底面 0.18 对齐。只改变可见几何，未增加碰撞体。

本包的机关状态、轨道逻辑连接、推动速度、停靠、存档与谜题顺序均沿用 v0.48.0。本次没有修改 paper_mill_state.gd、paper_mill_room.gd 或 save_book.gd。
