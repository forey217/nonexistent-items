# 星系仪引路转场 v01

按方案②替换启动界面进入大厅时的整屏深蓝淡入淡出。

- 点击“进入观察局”后，标题与按钮先淡去，镜头沿室内插画靠近右侧星系仪，持续0.48秒。
- 星系仪周围出现少量蓝金轨道、细小星光，亮度限制在仪器附近，保留木色、暖灯和黄铜。
- 保留最后一帧插画，把大厅真实星系仪的投影对准它；从仪器中心柔和展开大厅，再用0.72秒拉回正常镜头。背景只在展开边缘短暂交叠。
- 保留现有衍月从裂隙进入大厅的动作，以及等待玩家靠近或点击特斯拉后再开始交谈的流程。镜头转场约1.2秒，之后角色入场和停稳另约1.65秒；再次进入的角色停稳约1.2秒。
- “动态画面：关”时使用0.48秒静态淡化，不移动镜头、旋转星光或展开圆形过渡。
- 转场与角色入场期间锁定移动、选关与返回；声音M、全屏F11继续可用。音乐实例保持连续。

实现位于 `bureau_entry_transition.gd`、`bureau_entry_reveal.gdshader`，与现有 `start_menu.gd`、`game_flow.gd`、`hall_entry.gd`衔接。不修改世界规则、关卡机关、对话内容或大厅美术资产。

独立运行包：`builds/星系仪引路-v01/世界不按说明书.exe`。

验证：实机菜单集成检查涵盖图案对位、输入锁定、声音快捷键、镜头恢复、关闭动态效果、返回主界面、重复进入、星系仪水晶选关及进入第一关；报告随运行包提供。
