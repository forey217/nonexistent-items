# 倒悬实物响应 v0.54.0

以移动提速整合 v0.53.1 工作区为基础，保留既有修改。

- 落料板、普通导轨及开放吊台共用真实局部高度、速度；倒悬向 1.5 米平衡高度升起并减速。封存架、导向井沿用 2.3 米机关高度，锚定镇纸保持稳定。
- 吊台货物在台面之上浮动，水平轨位仍在吊井内。台面撤走时保持悬空货物的世界高度，不把货物拖着下降；重新接触实际台面后恢复承托。存档允许这种有界的离台高度，没有新增锁扣。
- 落料板只在山纹真正落回板面、检修撑已解除且上层为重力时破裂。局部离地高度转为跨层绝对高度时保持位置连续；跨层受力仍按所在高度选择层规则，并限制在原落料井柱内。
- 地面软投影留在实际支撑面；悬停高亮随物体升降。原有点击投影与任务共鸣继续读取真实高度，原水平阻挡保留。
- 每层 10 处小细节：4 张原晒纸垫纸片、2 张托盘纸片、2 片竹片和 2 条一端固定的纸条。纸垫原静态纸片被替换而非叠加；独立层规则驱动，范围有限，不参与玩法。停用原全场纸粒子。
- 可动细节在世界胶片静态环境捕获之后创建，两个胶片共享唯一真实姿态。暂停冻结，低动态减少摆动，读档按实际规则重建装饰姿态；镇纸仍走存档真实状态与稳定检查点流程。

没有新增外部素材或全屏模糊。新增 20 个局部装饰组与 2 个软投影；装饰最多 5 段纸条，材质复用，透明渐变仅用于小投影。
