# 水岸护栏整合 v0.53.0

快照 20261024-03。以任务开始时最新工作区（v0.52.0 世界胶片整合及已在工程内的归档门改动）封存为基础，补齐第二关固定禁行水岸的可见护栏。旧程序保留，不上传 GitHub。

## 补栏位置

- 上下两层中央横渠：两岸及两端收口，共 12 段固定低木护栏；中间运输桥正面与背面的开口保留。
- 上层显影旧廊水沟、下层西侧固定水沟：两岸及端部，共 12 段固定低木护栏；西沟原有桥头开口保留。
- 两处桥梁的上下层桥面两侧，共 8 段扶栏。上层扶栏挂在原桥面节点下，随显影、固定或隐藏状态一起显隐；下层固定桥扶栏保持可见。

合计 32 段。木立柱配上下横杆与低饱和暗铜箍，柱脚放在窄石岸座上，栏高约 0.78。使用已有木材纹理，不加发光和交互提示。当前镜头里遮挡人物的护栏会局部平滑淡化。

## 保留开口

中央运输桥、显影旧廊桥与下层西沟桥只加两侧扶栏，没有横杆封住入口。主桥开口宽 1.6，对应原先 1.2 宽的脚底中心通行范围及人物脚底半径。原显影规则、留影夹固定、轨道、吊台井口、落料口、自动楼梯与机关范围不变。

东侧长水面中仍可行走的装饰区域没有新增护栏，避免本次把原可走区域封闭。既有吊台、落料口和楼梯护栏继续使用原有实现。

## 实现与范围

新增 scripts/paper_waterbank_guards.gd，由 paper_mill_view.gd 构建和同步；没有修改 paper_mill_room.gd、paper_mill_state.gd 或 save_book.gd，没有增加 2D 碰撞体或改变导航。护栏上的专用 3D 射线体只服务遮挡淡化，不参与角色移动，也不截获地图鼠标操作。

新增护栏纳入世界胶片环境渲染。显影桥侧栏在旧世界胶片中隐藏、新世界胶片中出现；切换、暂停、演示恢复继续沿用现有流程。保留圆角轨道、方向箭头推动、低音量软底脚步、任务机关共鸣、存档与两关流程。
