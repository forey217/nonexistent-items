# 楼梯角色朝向修正

上下楼梯原先由房间脚本直接更新位置，绕过了人物移动器根据速度更新朝向的逻辑，导致人物保留踏入楼梯前的朝向，看起来侧身或倒着走。

现在进入楼梯时，按当前楼层到目标楼层的楼梯方向调用人物已有的 `face_toward()`。这个世界方向贯穿上下楼及落地阶段，渲染器继续根据实际镜头角度选择人物正反面和左右朝向。楼梯路线、移动时长、落地位置和存档逻辑保持原行为。

修改位置：`game/scripts/paper_mill_room.gd` 的 `_update_stairs()`。

验证：`game/tests/stair_facing_checks.gd` 从侧面真实走入楼梯，分别检查上楼、下楼，以及镜头-45°、0°、45°。全程逐帧检查行进朝向、角色显示朝向及落地后朝向，原生渲染30项通过，headless30项通过。纸山v02现有交互、楼梯、投影及界面回归36项通过。

运行：`builds/楼梯朝向修正-v01/世界不按说明书.exe`。

原生上下楼截图与报告：`showcase/checks/stair-facing-v01/native/`。
