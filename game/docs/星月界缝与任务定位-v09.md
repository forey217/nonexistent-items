# 星月界缝与任务定位 v0.9

主任务为“稳固世界关系，返回机构”。三个阶段依次为“先定星位、再压月痕、最后封界缝”；阶段目标不显示具体操作，H提示保留逐级线索和明确解法。

地图对应：
- 星位：第一处压板和挡块旁的黄铜五角星铭牌，完成条件仍为挡块释放。
- 月痕：末端高处接收器的新月印座，向上接触完成记录。
- 界缝：归位门里的紫色分叉裂隙，末端压力维持时修复为绿色封印；末端压板有相同裂隙纹，作为环境线索。

悬停当前分任务或主任务定位当前目标，悬停列表任一行定位对应目标，包括完成与未开始的阶段。对象图案、光环、材质和名牌增强亮度；移开约0.15秒渐暗。UI悬停不自动移动、不切世界、不推进谜题。标记是场景空间中的装饰，光环与名牌通过当前相机投影，跟随左右45度旋转；不新增实体墙或改动寻路。

特斯拉带领衍月入职观察局、讲解平行世界错位重叠及镇纸稳定锚点的开场已记录。口诀同上述三个阶段。后续拟在到达对应位置时，于屏幕一角展示漫画对话。本版本不接入对话、漫画、NPC或触发器。当前仍用一枚镇纸和三种世界规则；错误操作加重乱流的惩罚尚未引入。
