# 第二关《纸山叠影》朝向直接推动 v06

日期：2026-10-23。

## 玩家流程

去掉止挡选择标题、目的地按钮及关闭按钮；旧界面兼容节点保持隐藏，没有可交互内容或相机占位。靠近镇纸、站在后侧，面向轨道按E／右键即触发一次推动。约0.45秒动作结束即恢复人物移动，镇纸继续滑行。

方向取人物逻辑世界朝向，按主轴吸附；相等对角线固定优先X，避免不确定选择。推动方向在自动人物转身前保存。人物必须处于该方向后侧，允许有限侧向容差；没有相连轨道、错误站位、错误规则或浮空时返回简短反馈，不自动选择其他出口。

较远右键寻找所朝方向的可达后侧，实际走到操作点后再交互。预览与提交共用 `push_preview()`；状态验证及方向解析共用 `push_error()`、`push_choice()`、`push_direction()`。E优先选取人物近处前方的镇纸，避免桥边夹环比镇纸更近时造成目标不一致。

## 逐段轨道

水纹轨道新增封存架转角、导向支路口、水闸转角、导向井转角；山纹新增下层吊台转角和上层锚座转角。各边均为一条轴向直线，分岔口和转角均停下。中间停靠点采用现有材料的低矮铜色轨道接头标记。

下层水纹：封存架→封存架转角→接物踏板→中央止挡→导向支路口；从支路口可直走水闸转角再换向到水闸，也可沿已解锁支路前往导向井转角，再换向抵达导向井。

下层山纹：接物区→中央止挡→吊台转角→吊台。上层山纹：吊台→固定中转台→桥后止挡→锚座转角→锚座。各段均支持合法反向推动。

保留工程现有运输中禁切世界、吊台停稳、低位通道、显影桥及夹子联锁。双层独立规则、跨层落物、水轮吊台、双锚及归档返回继续使用真实状态驱动。

## 表现与存档

镇纸旁的世界空间箭头随逻辑朝向变化，浅绿表示可推、橙红表示条件不满足；相机投影后仍保持正确世界方向。短状态提示避让箭头，不再为原止挡面板移动镜头。

存档沿用版本2的载荷，增加合法转角station名称，不要求旧存档新增字段。运动中继续只保存最近稳定快照，停靠在转角时可正常写入并通过新进程继续。两个镇纸ID按原索引唯一恢复。

自动通关使用 `paper_push_driver.gd` 规划下一段，再通过实际寻路、逻辑转身和 `request_interaction("w0"/"w1")` 推动。玩家入口不接收目的地参数，演示不调用指定目的地的隐藏运输入口。每段等待真实运动与到站结果。
