# 任务物件联动精修 v01

本次在当前工作区基础上精修第二关任务物件，并将通讯、真实场景对象和透明物件展示连接起来。第一关剧情、语音 ID、存档格式和解谜状态机没有为展示效果改写。

## 使用

正常从存档进入第二关即可体验。首次介绍会展示对应物件，后续提及主要进行场景回应；分级教学提示允许再次展示。点击任务定位、或在 H 观测记录右上点击“物件图鉴”，可以再次查看，使用“下一件”和“定位实物”浏览。透明模型区域允许地图操作，只有真实按钮拦截输入。

## 实现

- `paper_mission_model.gd` 构造留影夹、山/水镇纸、各类踏板与锚座、夹环、吊台的实际几何。场景和展示复用相同脚本；没有截图代替模型，也没有新增位图纹理。
- 留影夹具有双夹口、深色内衬、转轴、回位弹片、铜刻度及竹纸薄片。取走后工具托内的实物隐藏；固定时显示在真实夹环上，召回、转移跟随实际状态。
- 镇纸保留原玩法尺寸和轨道关系，增加稳定底座、旧铜边件，以及形状不同的山脊、水纹浮雕。接物、重压水闸、山纹锚座和高处水纹锚位分别采用不同中心纹样。
- 踏板保留低安装座、接缝、弹性行程结构，移动承压面直接读取已有模拟状态。通讯强调只改变局部材质，不会伪造受压或成功状态。
- 夹环具有厚环体、开口、扣舌与安装座，闭合关系读取真实固定状态。
- 吊台增加台面梁、铜吊耳、导向和到站刻度。提示按台沿、提升连接、真实目标楼层到站刻度依次回应；不会改变高度或联锁。
- `paper_mission_cues.gd` 显式指定剧情节点/提示级别的对象 ID 与语音锚词。使用现有音频清单逐词时间，不从整段话猜场景目标。已有文本中缺少匹配录音的提示，明确标记为阅读时间估算，不冒充逐词同步。
- `paper_mission_guide.gd` 负责统一淡入淡出、物件现址、同层角标与屏幕外/另一层指示。连续提及保持当前亮度；暂停、取消、任务失效和读档经现有通讯生命周期清理。恢复阅读时按不可变语音 ID 找原始句序，避免过滤已读句后误配对象。
- `paper_mission_exhibit.gd` 沿用第一关镇纸介绍的透明三维物件、铜色短弧与真实字体排版。稳定三分之四视角，只有一个可按需更新的独立视口，关闭或暂停时停止渲染。按人物、当前目标、记录面板选择安全侧边位置；普通通讯不接管相机。

## 功能边界

没有增加任何互动距离、固定目标、碰撞面或自动解谜。隐藏旧廊仅标记入口，不显现实桥、不提供支撑。已有朝向推动、自动楼梯、护栏、防折返、吊台乘坐、双层独立规则、薄玻璃 UI、环境显影、相机和存档流程保留。

## 验证方式

使用 Windows Godot Compatibility / ANGLE 图形程序进行场景截图和自动输入回归，另在最终导出的 Windows 程序上复测。专项检查覆盖同源模型、真实状态联动、配音时间、取消/暂停、取走/固定/召回、屏幕外与另一层指示、隐藏旧廊、UI 输入与 0.55/1.0/1.6 倍率、1920×1080 和全屏。

录像由 Godot Movie Maker 直接记录实际图形与游戏音频，再转为 MP4，不后配语音、不合成演示画面。自动回归与录制使用固定逻辑帧率，不能作为玩家手工通关或实时性能基准。完整结果、对比截图及日志随独立 Windows 版本交付。
