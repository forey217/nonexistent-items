# 镇纸初见展示 v0.32

触发于开场特斯拉的“先锚定，让每个世界找回自己的位置。我们用这个——镇纸。”，通过台词的exhibit字段显式指定。逐字显示到“镇纸”时开始；玩家点击显全句也立即触发展示，不提前剧透后半句。

屏幕中央使用透明SubViewport呈现镇纸，复用calibration_scene_builder.gd的weight()实际几何及材料，形状与第一关一致。物品以约0.48秒淡入、上移和轻微放大，随后轻微悬浮、缓慢摆转；下方加入黄铜轨道光环、物品名和“用于锚定重叠的平行世界”。展示整体位于(410,95)—(870,530)，与底部对话框和右侧特斯拉立绘分离。框体、文字和物品均实时渲染，没有生成新图片。

继续至下一句、Esc跳过、切场景和清空对话都会立即收起，并将额外SubViewport切到UPDATE_DISABLED，普通对话和关内字幕不会误触发。

专用对话检查新增：普通台词不展示、逐字显示时机、真实模型、避让对话/立绘、继续后停止渲染、跳过后清理。保持原有完整通关及对话检查。

--paperweight-preview可从大厅的这一句开始预览，之后仍继续正常剧情与第一关；普通启动流程不变。Windows试玩位于builds/tutorial-v32，检查报告与原生截图位于showcase/checks/v32。
