# 第二关《纸山叠影》楼梯洞口护栏 v05

日期：2026-10-23。

## 空间与外观

依据现有上层洞口 `Rect2(2.5,3,2,5.5)` 布置护栏：两条长边分别位于x=2.4、4.6，z=2.9—8.4；远端短边位于z=2.9。近端保持敞开，衔接上层入口(3.5,8.8)。下层入口(3.5,2.8)前方保持通行。

平台护栏顶部约高1米，长边立柱间距1.1米。坡道两侧扶手使用踏步上的实际支撑点，向上连接平台护栏；下端立柱位于(2.65,2.5)和(4.35,2.5)，入口净宽保持可供人物通过。

木扶手、立柱采用现有纸坊木纹材质的深褐变体，石质柱脚与边缘基座采用原石材，连接套箍与销头复用旧黄铜材质。全部为真实三维网格，无新增AI位图或外部素材。

## 交互、碰撞与导航

`paper_mill_stair_guards.gd`集中定义护栏边界和真实几何。房间据此建立StaticBody2D与移动扫掠边界，角色圆形脚部尺寸与导航通行判断一致。几何包含真实StaticBody3D碰撞，用于空间遮挡及形体检查。

普通寻路暂时避开楼梯入口周围的自动触发区域，路径平滑亦遵守该边界；明确以楼梯入口为目标时保留自动上下楼。这样点击护栏另一侧可绕行，途经入口附近不会意外换层。

自动上下楼期间人物受已有流程锁定，暂时停用楼层护栏的二维碰撞；三维护栏保留，到站后恢复对应楼层二维碰撞，避免把已经下降的人物错误挡在上层栏杆处。原有朝向、相机高度跟随和楼板剖切继续使用。

旧存档若落在新增护栏位置，查找原楼层最近合法位置，避免因上层坐标回退而误换层或触发楼梯。存档结构及机关状态未改。

## 遮挡

使用相机到人物多个稳定身体高度的真实三维射线判断前景护栏遮挡。命中的护栏段及其柱脚、基座平滑淡化，未命中的段恢复正常。

Compatibility渲染路径采用每段独立的透明材质，不依赖该路径不支持的GeometryInstance透明度。可见状态改变不影响角色移动边界；上下楼时与现有楼板剖切同步显示两层联系。
