# 接待大厅满构图 v01

本次仅重新组织接待大厅。参考用户提供的2.5D地图截图的满屏构图和连续空间，保留观察局的象牙白、深蓝、黄铜、胡桃木与宇宙舷窗，不采用参考图的雪地和部落题材。

## 画面与地图

- 大厅扩展为17×17逻辑单位的可行走范围；地面和两侧立面延伸到画面之外，不再显示完整菱形底座和四周空白。
- 后方档案墙、右侧宇宙舷窗、较高的墙面结构共同封闭画面，两侧设置沙发等候区和绿植。
- 保留办公桌、特斯拉、星系仪、人物比例及既有的对话、选关、裂隙出入流程。
- 镜头采用边缘跟随，中心区域活动不移动镜头，人物接近画面边缘后平滑跟随。R同时恢复人物起点与初始镜头。
- 前方边界以低玻璃隔断提示，地砖继续延伸，避免重新出现悬浮平台的完整轮廓。

## 交互与遮挡

鼠标点击统一从屏幕坐标转换为当前镜头下的世界坐标，覆盖地面移动、星系仪与NPC点击。较大的寻路网格仅用于大厅，支持负世界坐标；教程仍沿用原寻路实现。新增家具均有实际碰撞与寻路避障，按Y坐标排序；遮住人物时适度淡化。

本次未修改第一关的地图与解谜规则。工程中现有的剧情、镇纸展示及其他更新继续保留。

## 美术来源与提示词

沿用`assets/interior_v30`的室内墙面、地面、办公桌与星系仪。新增沙发、绿植由内置image_gen生成，使用真正的透明背景；仅裁去透明边距，完整提示词、参考图及处理记录保存在`assets/hall_v34/SOURCE.json`。运行时资产分别为`waiting_sofa.png`与`planter.png`。

## 验证与运行

扩展后的大厅检查包含家具碰撞、负坐标寻路、镜头边缘跟随、移动镜头后的点击移动和星系仪互动、R复位，以及实际选关、三世界解谜和通关归档返回大厅，共43项。

原生实机与导出包的大厅43项检查均通过；导出包另通过现有剧情63项检查。检查结果和大厅截图随独立预览导出保存。

独立预览导出放在`builds/接待大厅满构图-v01/世界不按说明书.exe`。正常启动进入现有主界面；传入`--hub`直接进入大厅。开发工程入口仍为`game/project.godot`。
