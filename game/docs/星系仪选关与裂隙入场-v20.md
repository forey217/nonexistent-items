# 星系仪选关与裂隙入场 · v0.20

2026-10-21，《世界不按说明书》。

## 大厅与入口

正常启动先进入接待大厅。移除大箱子及其碰撞、寻路占地；特斯拉按照官方角色参考转换成 2D 形象，站在办公桌后，参与深度遮挡并有脚下碰撞。仅摆放 NPC，本轮没有添加漫画或对话剧情。

取消左上角直接进入关卡的按钮。点击星系仪可打开选关界面，靠近星系仪后按 E 也可打开。选关时冻结大厅操作，按 Esc 或“返回接待室”可以关闭；已经开始入关过渡时不会重复触发或中途切换。

## 水晶星图

背景由实时流动星空、柔和星云、黄铜色轨道线和五道漂浮裂隙组成，沿用奶油白、铜金、冰蓝与灰紫配色。只有一枚可选关卡水晶：“新手校准室”。其他裂隙是代表冰晶、重力、倒悬规则的背景景观。

点击水晶或进入按钮后，五道平行世界裂隙沿弧线汇入关卡水晶，带各自颜色的光流。水晶随后从自身中心放大、变亮，在亮光遮罩下切换场景，再柔和显露校准室。选择过渡约 1.97 秒，音乐连续，M 键始终可静音。

## 裂隙出场

进入校准室和通关归档返回接待大厅后，都会出现短暂空间裂隙。衍月从裂隙中淡入、迈出约两步，裂隙随后合拢，恢复操作，持续约 1.1 秒。

入场使用真实人物移动和原有碰撞检查，不直接穿过障碍。校准室裂隙使用小型实时纹理及 3D 竖直纸片，跟随相机投影并参与深度遮挡；动画结束后关闭额外渲染。大厅使用同一裂隙绘制风格。重置会清理入场状态。

原有封界收尾、盖章归档和抛物线入柜都保留，归档之后衔接大厅裂隙出场。
