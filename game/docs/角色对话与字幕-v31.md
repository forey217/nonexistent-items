# 角色对话与字幕 v0.31

2026-10-22。依据已审阅的开场至第一关收尾脚本，以及六张对话UI提案接入原生Godot界面。

## 表现与操作

- A剧情框：纸白切角、黄铜细线、错位纸层、姓名页签。衍月左半身像，特斯拉右半身像。用于首次大厅接待和第一次通关收尾。现有站酷小薇体用于姓名与剧情正文，26px正文。逐字显现；点击、空格、回车或E先显全句，再继续；Esc或跳过按钮跳过本段。模态期间暂停当前场景，音乐、静音和全屏仍可用。
- B关内轻框：小头像、通讯标记与独立操作提示；姓名保留宋体风格，正文使用Windows微软雅黑/Noto Sans CJK回退，中黑22px。最多两行，显示在y=707—795的原底部信息区，隐藏该区旧文字，保留任务栏、世界按钮、机关和角色完整视野。不中断行走、推动和切换世界，不需要点击继续。
- C短句框：相同安全区内更窄的批注签，左/右头像沿用说话人方向。星位完成时衍月短句、封界后特斯拉确认各使用一次，其余即时反馈优先字幕。
- 无框字幕：25px浅色字、深描边，固定底部安全区。用于入场、选关、滑行/上浮/月痕反馈、归档和普通操作提醒。与世界胶片错位效果分离，不发生文字重影。
- 点击大厅特斯拉，或靠近后按E，可重开当前上下文对话；星系仪交互优先级保留。

## 触发

|节点|触发依据|显示|
|---|---|---|
|开始旅程|菜单淡出完成后首次进入大厅|A，初见/世界重叠/镇纸/安排任务|
|选关水晶|完整、展开两种实际状态|字幕；进入动画开始立即清空|
|第一关入场|裂隙结束后|字幕目标说明，随后B首次冰晶规则；重玩为简短开场|
|首次有效推动|镇纸真实开始滑行|字幕|
|第一踏板|镇纸停在踏板且星位未锁定|衍月B观察，特斯拉B解释重力与位置保留|
|星位完成|first_latched实际成立|衍月C、后续字幕；不会在只按切换键时提前报成功|
|末端|镇纸真实抵达且月痕未完成|B倒悬教学|
|月痕完成|receiver_latched实际成立|字幕，提示封界踏板|
|界缝封合|封合动画结束、gate_ready成立|字幕与特斯拉C，提示维持重力后走进归位门|
|末端失压|门开后切换导致gate_ready撤回|字幕及B恢复压力提示，不重复全套成功对话|
|归档|实际走进归位门|字幕，无需点击；保留现有动画时长|
|返回大厅|归档、返回裂隙均结束|第一次A收尾；后续不自动重复长对话|
|H/R|玩家主动请求|B逐级提示 / 清空旧队列、简短重置|

`dialogue_script.gd`保存台词；`bureau_dialogue.gd`按状态调度；`dialogue_view.gd`排版与输入；`dialogue_panel.gd`原生绘制框体。阶段变化清除当前及待播的过期台词，跳步时不补播失效指令；已播阶段不因镇纸回滑重复触发。世界变化后，尚未出现的“现在是冰晶”改为邀请切回冰晶。停留无进展时只给一次当前阶段补充提示；H可继续主动求助。

## 素材

衍月透明半身像由内置image_gen基于已有分件和已批准A款形象生成，记录见`assets/dialogue_v31/SOURCE.json`。特斯拉沿用`assets/npc/tesla_v01.png`。人物仅通过运行时AtlasTexture读取半身/头像区域，不改写原图。框体原生绘制，正文是真实可排版文字，未将整张概念设计板作为界面贴图。

## 验证

专用入口：`Godot --path game --fixed-fps 60 -- --dialogue-check --artifacts=<绝对目录>`。该入口使用正常启动界面及真实对话，检查输入隔离、跳过、NPC重谈、选关字幕、真实推动/切换/压板/归档返回、过期台词清理、门失压恢复、重玩/R、全部长句排版、±45°机关可见性，并保存原生截图与JSON报告。旧玩法测试入口关闭自动剧情等待，仅检查原有行为；专用对话检查保持剧情开启。

最终原生截图与报告复制到`showcase/checks/v31`，试玩程序在`builds/tutorial-v31`。未提交、推送或发布到外部平台。

最终结果：导出的Windows EXE以原生ANGLE渲染完成39项对话流程检查，0失败；原教程66项、接待大厅完整流程36项、启动界面29项检查均通过，共170项。逐图查看了两人剧情框、轻框、短句框、月痕字幕和归档后收尾；所有开场/收尾文本及关内轻框均检查了实际换行高度。对白正文保持文字渲染，±45°下底部轻框未覆盖三处主要机关的投影点。
