# 《纸山叠影》清晰度、自动楼梯与HUD v02

2026年10月23日。对应新程序：`builds/纸山叠影-v02/世界不按说明书-纸山叠影-v02.exe`。v01保留。

## 渲染与拾取

第二关保留1280×800逻辑画布。世界SubViewport按实际屏幕绘制比例使用1.25倍渲染，长边上限3840像素；MSAA由2倍改为4倍，输出线性采样。窗口变化时重建渲染尺寸，平时复用，不改第一关和大厅的全局基础分辨率。

世界投影和鼠标射线通过同一组逻辑／渲染坐标转换。屋顶遮挡检查也转换回逻辑屏幕坐标。角色Sprite使用明确的线性过滤；石板和屋顶减少细碎重复密度，保留各向异性mipmap采样。原始素材未后期锐化或编辑。

宽高比不同的窗口延续项目原有等比适配；例如2560×1440窗口的游戏绘制区域为2304×1440，世界渲染为2880×1800。HUD始终使用逻辑屏幕字号，不随地图滚轮缩放。

## 自动楼梯

人物脚底进入距实际入口0.42地图单位内后自动通行。入口与可见台阶投影连接，左键点击台阶映射至本层入口，普通地面点击仍使用地面射线。右键／E不再操作楼梯。

楼梯采用连续的接近入口、沿台阶升降、走出目标端三段运动；两层规则和机关继续模拟。相机在楼梯过程中跟随人物高度，避免开头突然切到两层中间。到站先落在出口侧0.36单位处，须离开0.95单位范围才能再次进入；原地停留不会反复上下楼。读档恢复在入口附近时初始化为未重新进入。

石台阶增加连续实体承托与铜色踏步边缘，保持与封闭的楼梯井碰撞区域一致。上下楼期间只对楼梯周围的上层楼板做局部剖切，让身体和台阶完整可见；到站后恢复。过渡期间仍回退到最近稳定快照。

## HUD与输入

墨青半透明底、暖灰字、旧铜细线。左上短任务可点击定位；顶部一组规则按钮及两层状态；左下两块镇纸和夹子；右下人物定位、提示与帮助。默认常驻面板占位低于逻辑画布15%。

H展开观测记录，按钮逐级显示提示。Esc打开暂停菜单，包含四路音量、恢复、重开、返回大厅／主界面、静音、全屏及退出。夹子召回仍在常驻状态项直接可用。首次教学和普通提示短暂显示，空闲时不再有全宽说明条。

第二关通讯使用窄幅墨色字幕和现有Q版人物素材，最多两行正文；普通提示与通讯互斥。成功保存后在右上显示短文字，第二关隐藏旧的白色音量、返回和保存卡；其他场景沿用原有界面。

相机定位／跟随根据当前展开面板和字幕计算安全区域。手动平移、旋转和指向点缩放会保留玩家构图。地图点击统一经过HUD区域检查，空白画布可以操作；UI上的滚轮不会穿透至地图。跨面板释放拖动按钮会结束拖动。
