## 操作

| 输入 | 操作 |
| --- | --- |
| WASD／方向键 | 移动，接管点击路线 |
| 左键地面 | 点击寻路；观察另一层时会提示返回人物 |
| 右键目标／E | 靠近后互动；镇纸会列出可连接的下一止挡 |
| 1／2／3／4 | 切当前观察目标层的冰晶／重力／倒悬／显影，共享1.5秒冷却 |
| Tab或上／下层按钮 | 切观察层，人物位置不变 |
| 滚轮 | 上滚放大、下滚缩小，约0.55—1.6视觉倍率 |
| 按住中键拖动 | 平移观察地图 |
| Alt＋左键水平拖动 | 旋转约正负45度 |
| F／回到人物 | 镜头回到人物所在层和位置 |
| 点击阶段任务 | 定位真实目标；悬停显示对应对象高亮 |
| H | 当前阶段三级提示 |
| R | 恢复最近稳定观测状态 |
| 召回留影夹 | 释放当前固定机关；人物占用木桥时拒绝危险释放 |
| 完整重开本关 | 清空当前第二关进展，重新开始 |
| Esc | 关闭止挡选择、取消行走和当前通讯 |
| M／F11／F10 | 静音／全屏／保存并回主界面 |

镇纸的下一站由轨道连接关系决定，按钮会列出分支和可回滑方向。冰晶负责运送，重力负责重压，倒悬负责触顶，显影负责找回缺失结构。人物必须抵达可操作的一侧，观察层切换与远程切规则不会传送人物。

## 通关路线

上层显影取夹子 → 经楼梯下层倒悬开封存架 → 冰晶运水纹至接物踏板 → 重力升接物台并夹住 → 下层冰晶、上层解除检修撑并切重力 → 山纹落到下层 → 冰晶将山纹送入吊台、水纹送往水闸 → 下层重力驱动吊台 → 上层冰晶将山纹推出到中转台 → 召回夹子、显影夹桥、冰晶过桥送山纹至锚座 → 上层重力锚定并打开下层保护罩 → 下层冰晶移走水纹、吊台归底开低位通道 → 水纹经中央止挡至导向井、倒悬上浮 → 回上层走归位门。

## 实现边界与维护

表现为正交3D场景，移动与碰撞判定使用分层逻辑平面、扫掠检查及AStar网格。镇纸运输使用确定性的轨道与连续运动，水路使用状态控制的水轮、闸板和流动材质。概念图用于外观与空间参考，没有作为整张可转动的背景直接铺入游戏。场景尚未追求与概念插画逐像素一致。

角色仍使用现有二维分件步态，通过透明SubViewport映射为竖直Sprite3D。屋顶按人物投影遮挡检查隐藏；工作坊附近高墙淡化，避免遮住角色头部。可动桥、楼板切面、屋顶与固定场景在静态合批时保持独立父节点。

新增模块为paper_mill_state、paper_mill_room、paper_mill_view、paper_mill_hud及paper_mill场景。game_flow按关卡ID路由，选关第二枚碎片按教程记录解锁；archive_return新增可配置归档标题。save_book版本2接受旧版本1记录，并校验第二关快照；新写入沿用临时文件、备份及原子替换。

稳定快照保留两层规则、镇纸站点／高度／层级、夹子目标、永久解锁、破板、升降和锚定状态。运动中保存回退到最近完整快照。角色位置若与恢复后的通路不兼容，会落到合法楼梯平台。进度按实际稳定状态保留，检查点描述用于说明当前主要阶段。

石板、木板、粗石墙、青瓦和竹林素材由内置image_gen生成；实际提示词与源文件路径见`game/assets/paper_mill/SOURCE.json`。竹林保留原生RGBA透明度；材质直接应用到真实几何，无后处理修改原始生成图。保留既有第三方音频与角色来源记录。流水底噪由代码生成，使用现有SFX总线。

## 自动演示与检查

`--paper-mill`：直接预览第二关，不绑定存档。

`--paper-mill-demo --artifacts=<绝对目录>`：从独立演示档经过菜单、选档和选关，再通过玩家共用接口自动完成第二关。记录阶段截图、连续演示时间与检查报告，使用独立存档目录。此入口提供实机演示路线，未生成配音或剪辑成片。

`--paper-mill-check --artifacts=<绝对目录>`：完整流程、输入、错世界恢复、占桥保护、存档续玩和归档检查。

`--paper-mill-resume-check --save-dir=<已有检查产物/reopen-save> --artifacts=<绝对目录>`：新进程恢复上一轮从真实游戏中生成的跨层落物存档。

`--paper-mill-visual-check --artifacts=<绝对目录>`：上下层四种规则、远近倍率及旋转边界的画面采样。
