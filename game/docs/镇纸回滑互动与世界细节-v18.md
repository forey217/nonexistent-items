# 镇纸回滑、互动动作与世界细节 · v0.18

2026-10-21，《世界不按说明书》。

- 冰晶世界的挡板未降下时，镇纸停在第一踏板。再次互动会反向沿轨道滑回起点，到端点停住；途中重复点击不改变速度或重新触发动作。回到起点后可以重新向前推，重力加重释放挡板的原解法保持。双向滑动都进行端点限制和停止音效。
- 右键或 E 会先靠近适合伸手的位置，再转向镇纸、伸手施力、收手。动作约 0.46 秒，到第 0.20 秒的接触时刻才推动物品。脚下保持原碰撞，不瞬移；远处互动沿安全路线靠近。重复输入不会叠加动作；重置、失焦会清理未完成的互动，世界切换等待短动作结束。
- 冰晶世界：两条轨道从起端逐段结霜，约 0.8 秒蔓延至末端，带小冰晶闪动，完成后保留薄霜。再次切回会重播结霜过程。
- 重力世界：电源柜脚、监测台桌脚周围，细裂纹从受力处向外短暂延伸，仅作为环境规则反馈；不增加障碍，不改变家具或人物碰撞。
- 倒悬世界：监测台上补充三张轻微旋转、悬浮的纸片，与既有上浮纸屑、摆锤和样品呼应。

新增几何全部由项目代码绘制，沿用原有材质配色；每个世界保持独立渲染层，参与胶片过渡。没有新增外部素材。

验证：新互动/环境 23 项、教程 62 项（1,341 次位置采样）、旋转 17 项、胶片 46 项、贴墙遮挡 27 项全部通过。实机检查伸手与镇纸接触、四个初始接近方向、逐段结霜与细裂纹；完整试玩经三世界机关、封界、归档动画回到大厅。导出后重复互动/环境检查。
