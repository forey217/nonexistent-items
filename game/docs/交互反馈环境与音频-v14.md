# 新手校准室 v0.14：交互、机关反馈、环境与声音

2026-10-21，基于 v0.13。此次按选定的第 1、3、4、5 项完善；NPC 漫画与节点对话暂不制作，解谜顺序和世界规则保持。

## 本次行为

- 悬停镇纸：轻微金色轮廓，短暂显示“右键互动 / E”，约 2.8 秒后文字消失，移开后淡出。轮廓按实际相机投影计算，支持 ±45° 旋转；悬停 UI、施法、拖动视角和封界收尾期间不出现。远处右键仍先寻路至安全位置。
- 月痕装置：侧柱新增 12 段细刻度，随镇纸真实高度逐段点亮，游标跟随高度。首次接触上部印座时出现约 0.48 秒的压印环和月痕响应，持续接触不会重复触发。
- 封界收尾：最终压力成立后，用约 1 秒让星位、月痕依次响应，青绿色能量沿地面线路汇入门框，裂纹收束、栅栏收起，再开放门口碰撞和寻路。期间短暂锁定人物和世界切换；结束出现渐隐的“世界关系已稳定”。人物之后自行走入归位门返回机构。复位可立即取消整段效果，已完成后失去、恢复压力不会重复播放收尾。
- 环境规则：冰晶世界少量冰粒贴地滑行；倒悬世界纸屑缓慢上浮，悬挂样品向上；重力世界摆锤向下拉直并短暂衰减摆动。装饰不增加碰撞和可交互对象。环境效果遵循世界渲染分层，能参与胶片切换。
- 音频：循环轻奇幻背景音乐，独立 Music/SFX 总线；补充世界折叠、规则落定、推动、碰撞停下、落地、星位、月痕、封界完成和按钮音效。配乐跨机构/教程持续播放，不叠加；左侧声音按钮或 M 键切换静音。背景 -24 dB，确认音 -14 dB，其他效果约 -18 至 -20 dB。正常关闭时先释放音频播放。
