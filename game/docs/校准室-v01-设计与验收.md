# 新手校准室 v0.1：地图、规则与验收

日期：2026年10月20日。用户批准先做玩法和地图，暂不接剧情。

## 本次实现

同一张斜俯视2D地图，三个平行世界轮流生效。地面12×8个等距单元，主视口1280×800，角色沿用已校准的v0.3行走组件。角色不跳跃，WASD与左键导航共用。镇纸活动导轨由实体护栏隔开，角色沿两侧通道走动，避免物品落下位置与角色重叠。

起点在左前侧；中央斜向导轨串起两块压板；末端有竖向导向架和顶部接收器；右侧为归位门。书柜、办公桌与铜色标记沿用机构的美术语言。校准完成后返回已有的观察局大厅，可自由走动并重新进入教程。

## 物理规则

- 冰晶：正常向下重力、导轨低摩擦；右键一次后镇纸以恒定速度滑到下一个挡块。角色或镇纸切换世界时不会回起点。
- 重力：向下重力为正常的4倍；镇纸可以压下两处重型压板，人物无法推动它。空中切入时连续加速下落，不瞬移。
- 倒悬：向上的重力作用于未固定物体；镇纸沿导向架上浮，达到末端上方接收器才记录校准。其他位置上浮不会误触发接收器。
- 散落纸张按同一重力方向上浮或落下，固定书柜/办公桌有铜色锚点。衍月以磁力靴贴地，操作方向不随重力翻转。
- 第一挡块通过机械锁定保持开启，顶部校准记录跨世界保留；末端压力则需要重力世界持续维持。切回其他世界会失去末端压力并关闭出口。

完整路径：1冰晶推动→2重力开挡块→1冰晶再推动→3倒悬校准→2重力落下→走进归位门返回机构。

## 操作与恢复

右键点镇纸或E交互；远处交互会先导航到护栏外的可达位置。点击镇纸只靠近，不自动推动。WASD/方向键可立即接管并取消旧路线和待执行交互。Q轮换，1/2/3直达世界，GUI按钮同样可用。H按当前阶段逐级提示，R重置全部状态，Esc取消移动，F2查看碰撞。

切错世界、滑行中途切换、悬空切换均可恢复。不能在悬空时重新推动。出口的抵达范围覆盖门体碰撞边界，避免切换时门体在角色位置重新闭合。失焦会取消待执行交互。

## 视觉范围

冰晶使用硬边分面、冰晶装饰与冰霜陈设；重力世界使用粗线、排线和漫画网点；倒悬使用透明色晕、颗粒和上浮纸张。同一布局与铜色机关标记保持识别连续，人物形象保持一致。

本版以已有机构素材、Godot绘图和运行时材质搭建，不新增AI生成图片。世界陈设尚未分别整套重绘，当前为首版可玩地图。正式关卡、AB/BC/CA同时双世界轮换、NPC、对话、漫画和剧情均未实现。

## 源码模块

- `scripts/game_flow.gd`：教程、机构大厅与重玩流程。
- `scripts/tutorial_state.gd`：世界规则、位置/动量、压板与校准状态。
- `scripts/tutorial_room.gd`：碰撞、导航、交互、提示与出口。
- `scripts/tutorial_map_art.gd`、`tutorial_machine_art.gd`、`assets/world_props.gdshader`：地图、机关与三世界表现。
- `scripts/tutorial_hud.gd`：世界切换、阶段目标和分级提示。
- `scripts/tutorial_hub.gd`：复用既有机构大厅。
- `tests/tutorial_tests.gd`：46项状态及真实移动/输入检查。
- `tests/tutorial_demo.gd`：从初始状态实际操作到返回机构的原生渲染走查，保存8张截图。
