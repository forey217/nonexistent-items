# 星系仪内部的世界封存室 · v46

本轮重制星系仪选关界面。新背景采用黄铜观测环、深蓝玻璃穹顶、木质边框和留白星空；中央为封存星光的六瓣星玻璃晶核。画面资源由内置 imagegen 生成，晶核在 Godot 内以六块真实挤出网格渲染，带倒角和侧壁，不是整张界面贴图。

## 已实现

- 标题为“世界观察局 / 世界坐标档案”。返回按钮沿用象牙白与黄铜。
- 晶核加宽放大，保持轻微悬浮。内部星光、表面反射和背景星尘缓慢运动；默认不因持续待机放大。
- 悬停约0.2秒出现沿分瓣边界的细裂光，移开恢复。
- 点击后约1秒展开为六块对应碎片，带弧线移动、轻微转动和黄铜定位环松开。
- 可进入碎片含静态关卡微缩图；锁定碎片为磨砂玻璃和问号。名称在悬停时出现。
- 保持第一关 / 第二关的原有解锁判断，未完成第一关时第二关仍锁定。
- 选择后其余碎片沿旋转轨迹汇入目标，带蓝白星尘和细金拖尾；目标转正、放大、增亮，画面旋转后进入关卡。总时长2.4秒，在2.18秒亮光峰值接入原有场景与星仪环门。
- 不再上下重复显示操作提示。首次会话保留特斯拉已有录音“轻触水晶，让坐标展开。”，展开后由界面短暂提示选关；不会重新配一条仅改用词的语音。
- 六块网格共用一个1280×800透明渲染视口。关卡微缩图为静态图片，没有启动六个关卡或六个视口。
- 点击区域来自实际3D投影的正面与侧壁，背景点击不会触发，进入期间禁止重复触发和取消。
- 离开菜单释放网格、视口、材质与动效；前台60帧 / 后台30帧上限继续保留。

## 保留内容

主界面、三档存档、已有稳定检查点、第一关谜题与1.5秒世界切换冷却、第二关入口、通关归档返回、四路音量和已接入的逐句配音均保留。不修改真实玩家存档。
