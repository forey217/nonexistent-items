# 大厅抵达与自由交谈 v0.37

将“先看见大厅，再开始对话”和“先自由走动，靠近特斯拉再交谈”结合。

首次从主界面进入时，总计约3.4秒：深蓝黑场在1.1秒内渐亮，0.55秒后浮现接待大厅地点名，0.7秒后播放已有裂隙声效及角色走入动作，最后让衍月站稳并面向特斯拉。过渡期间隐藏普通操作提示和返回按钮，阻止提前交谈、移动与F10切场景，保留声音与全屏快捷键。背景音乐连续播放。

过渡后恢复操作，特斯拉上方显示“特斯拉 · 靠近或点击交谈”。玩家可先探索，不设置自动弹剧情的等待时限。首次在特斯拉145像素范围内停留0.3秒，或用鼠标点击其立绘，即开始现有初见剧情。原有附近E键交谈入口保留。开始交谈立即收起邀请提示；跳过或完成初见后，留在附近不会重复触发。

同一程序运行期间，返回主界面再次进入大厅时过渡缩短为约1.55秒，保留已看初见的记录。完成关卡后的归档、裂隙回大厅及收尾剧情沿用原流程。专用镇纸和教学预览参数保留直接展示行为。

实现：`hall_entry.gd`协调淡入与入场动作；`tutorial_hub.gd`管理地点名和交谈邀请；`bureau_dialogue.gd`将初见从计时触发改为接近/点击触发。共享裂隙控制器新增入场步距系数，原关卡及归档回程默认步距保持原值。
