# 世界观察局与新手体验打磨 v43

## 范围

本轮打磨主界面、选档、大厅、第一关与归档复盘。保留当前工程的第二关、星仪环门、档案纸选项、三档存档、人物动作、碰撞、1/2/3切世界和1.5秒冷却，以及前台60帧/后台30帧与静态合批优化。没有接入语音，也没有修改已有存档结构。

机构正式名称统一为“世界观察局”，游戏名仍为《世界不按说明书》。更新大厅铭牌、主界面机构文字及入口、地图地点抬头、对话框抬头和归档页；自然语言中“局里”“返回观察局”等简称保留，存档目录与工程标识不变。

## 教学和提示

- 首次互动立即提示靠近镇纸后右键/E推动与冰晶低摩擦，随后说明1/2/3与位置保留、三步目标。全部为非阻塞交流，操作会继续推进真实机关并清除过期台词。
- 第一踏板首次明确教授重量与重力规则。星位完成后只默认描述目标、位置、机关已锁定及当前现象；不再自动报出冰晶运送、倒悬上升和重力封界的整套操作。
- H按当前真实状态提供三层：观察→规则→明确操作。新阶段重新从第一层开始，重复H直接替换当前提示。悬空但未到末端、月痕完成后又反向运走镇纸等状态有对应提示。
- 自动提醒要求35秒“有效等待”：对白阅读、裂隙入场、施法、推动动作、镇纸滑动/升降、封界、寻路/行走、旋转视角和不可操作状态均不累计。新的按键/点击、人物移动或物件/世界变化会重置等待时间。
- 每个阶段只自动提醒一次“需要帮助时，按 H 联系特斯拉。”，不自动播具体解法。

## 对白和配音资料

开场8句、回程5句，保留世界重叠示意和首次镇纸展示，由对应台词触发，继续/跳过时收起。

最终配音资料见 `voice-v43/`：CSV便于制作、JSON便于程序映射、Markdown说明包含完整开场与复盘。共74条独立文本，覆盖实际默认剧情、重玩、选关、H分层提示和特殊操作回应；不包含第二关独立对白。

编号为 `vo_角色_角色与精确文本SHA256前16位`。同一角色同一句话只需录一次，修改顺序不改ID，改文字生成新ID，避免旧音频误配。运行时对话历史也记录同一个ID。`game/tools/export_voice_manifest.gd` 可重新导出清单。

## 保存反馈

只在 `save_book.write()` 真实写入成功后通知“观测记录已保存”。无变化而跳过写入不提示，失败保留原档与原失败提示，不伪报成功。

共用一个轻量绘制节点，象牙纸、黄铜细线、深蓝墨字、圆印勾，淡入0.15秒，总时长1.4秒；相邻1.8秒内写入合并显示。鼠标穿透，不暂停，不增加确认。大厅在右上功能键下方，第一关在右侧世界说明下方；对白大框、入场及切场景时隐藏。

## 实机节奏测量与验收

第一轮实际ANGLE图形运行：从主界面点击进入开始，全读8句开场，以12字符/秒、每页额外0.25秒且最少1.2秒作为可复现阅读模型；经实际桌前寻路、完整选档与水晶转场、裂隙入场，并实际靠近镇纸完成接触动作。首次推动实测37.806秒，物理模拟时间27.917秒。没有跳过开场、加速游戏或通过传送跳过首次路径。

这是固定路线和阅读速度的自动化基准，不是陌生玩家试玩结论，也不保证每位玩家45秒内完成。正式配音时长确定后需要重测，玩家自行探索也会增加时间。

49项专项检查覆盖完整开场/跳过、第一关完成及五句复盘、真实桌前寻路、H逐层与替换、35秒有效等待、各类动画与阅读不累计、动作重置等待、真实成功/无变化/写入失败的反馈、连续写入合并、稳定音频ID和旧v39版本1记录读取。所有测试存档为隔离目录，不写玩家实际记录。

已进行实机截图检查；后续仍建议由未看过解法的玩家试玩，观察是否能自行发现倒悬规则和持续压力。本轮不扩展关卡和装饰，不上传GitHub。

最终整合包再次完成49项实机专项检查，零失败；该轮首次推动28.696秒（模拟27.983秒），此前两轮为35.773秒和37.806秒。三轮均采用上面的固定阅读路线，差异包含加载与实际运行负载。其余菜单/音量58项、存档48项、剧情93项、性能/资源释放23项、解谜66项、世界切换34项、第二关保留147项检查通过。截图与最终报告随 `builds/tutorial-v43` 保存。
