# 四项音量与配音通道 v0.44

选项页改为四条0%～100%滑竿：总音量、背景音、音效、对话语音。保留档案纸纹、小黄铜夹、站酷小薇标题、思源宋体和精密刻度滑块。纸页调整为580×640，居中显示；下方操作说明与返回保留，键盘上下和Tab可依序访问所有滑竿及按钮，左右调节当前音量。

## 音频关系

- 总音量对应Master；背景音对应Music；音效对应SFX；对话语音对应Dialogue。
- Music、SFX和Dialogue独立输出到Master。实际输出是分类音量与总音量的乘积，0%直接静音对应总线。
- 现有持续音乐走Music，菜单、机关、入场和环境音效走SFX。
- Dialogue总线已建立，供接下来的配音接入；本次尚未添加语音文件或自动朗读。配音播放器设置`bus="Dialogue"`即可接受对话语音和总音量共同控制，不要路由到SFX。
- M键和大厅声音按钮只切换总音量，保留三类独立数值，恢复时返回原总音量。

## 保存与兼容

沿用Godot用户目录`audio_settings.cfg`，原`volume`和`audible_volume`字段保留，新增`music`、`sfx`、`dialogue`。旧配置缺少新增字段时使用100%，保留原先的整体响度。读入时检查数值类型和有限性，将音量限制在0～100%。

滑动停止约0.2秒后自动写入，关闭选项和正常退出时补写。与三档剧情存档分开，不互相覆盖。
