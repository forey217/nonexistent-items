# 校准室视角旋转 v0.4

## 操作

按住**左Alt**和鼠标左键，水平拖动鼠标，绕房间中心旋转。每个逻辑像素对应0.2度，范围为-45至+45度；到极限后不会绕圈。松开任意一个按键即停止，保留当前角度。右Alt不会开启旋转。

右上角显示角度，“复位视角”恢复默认斜俯视角度，不改变人物、镇纸或校准进度。R仍重置整个教程，并恢复默认视角。切出窗口会清除拖动和Alt状态，避免重新激活窗口后继续误转。

Alt+左键事件在GUI与地面点击处理前消费；开始拖动时取消原自动行走和待推动指令。普通左键继续移动，右键继续交互。WASD按当前画面方向控制，界面、文字、CD按钮不随世界旋转。

当前仅为新手校准室增加此功能；返回机构大厅后使用大厅原有视角。

## 实现

固定图块无法提供新的观察方向，所以本版复用已有Kenney CC0模型和自制机械几何，增加实时正交显示层。外观仍使用原材质、30度俯角、纸片人物与无跳跃设定。`calibration_scene_builder.gd`被实时视图和离线图块工具共用，便于继续维护。

- `tutorial_orbit_view.gd`：三种世界的显示、相机、拖动、输入投影、世界读数和2D人物视口。
- `tutorial_room.gd`：地面点击先与当前相机下的地面求交，再交给原导航；镇纸按实际高度投影命中，设备按投影边界命中。
- `yanyue_mover.gd`：新增默认恒等的`input_basis`，将屏幕方向转为原碰撞空间方向，保留原步态和碰撞逻辑。其他场景默认行为不变。
- 人物以双倍分辨率渲染2D分件动画，随后作为朝向相机的纸片显示；身体姿态随当前屏幕行进方向选取。模型正常参与深度遮挡，脚底使用同一地面坐标。
- UI保持CanvasLayer；原2D物理层不旋转、不缩放。轨道位置、竖直高度、重力、碰撞、导航、压板和3秒CD保持原规则。

已按要求保留设备本体，移除“场律电源 · A”和“校准监测 · B”两处标题标签。其余机关状态读数保留。
