# 第二关显影生活遗物 v01

第二关《纸山叠影》的显影规则增加12组生活遗物：上层7组、下层5组。包含空椅、带旧杯和纸页的小桌、褪色相框、枯植物、晾挂衣物、散纸与残墙装饰画。材质沿用纸坊的旧木、灰绿陶器、灰黄纸布和石灰墙色；物件分布在院落边缘、工具场侧边和后沿，保留中央通路与机关周围留白。

## 表现

- 普通世界完全隐藏，无碰撞、可拾取物、交互标签或任务提示。
- 每层独立读取该层规则，切换显影后约1.8秒分批浮现，先出现淡边，再铺开纸木肌理和实体颜色。
- 三组遗物保留局部缺失；四组带轻微错位重影。切离显影后主体约0.55秒退去，少量重影继续短暂残留并完全消散。
- 画面使用低饱和漫反射，无额外光源、发光或阴影残留。装饰画连同一小片残墙显现，相框带支架，避免脱离环境悬空。
- 所有物件挂在原有楼层显示根下，跟随观察层切换。旧廊、显影桥与留影夹仍由原有玩法逻辑控制；遗物不能用留影夹固定，也不写入存档。

## 文件

- `scripts/paper_mill_memory_props.gd`：布局、程序化几何、独立显影进度与残像。
- `shaders/paper_memory.gdshader`：由淡边到肌理和实体的渐显、局部缺失与错位重影。
- `scripts/paper_mill_view.gd`：创建遗物并在现有画面更新中同步楼层规则。
- `tests/paper_memory_checks.gd`：13项专项检查及普通状态、渐显、完整显影、残像、下层和全景截图。

## 验证

在Godot 4.7.2 Compatibility / ANGLE实机运行专项检查，13项全部通过。检查涵盖上下层独立、分批显现、半显形与重影、切换后残像清理、快速反复切换，以及动画不改变存档快照、目标列表和同一规则下的寻路结果。

```powershell
Godot --path game -- --paper-mill --paper-memory-check
```
