# 纸山叠影 · 木铜卷轴归档门

独立版本：v0.53.0 / 20261024-03。程序位于 `builds/卷轴归档整合-v0.53.0/世界不按说明书.exe`。保留任务开始时的 v0.52 世界胶片与演示改动，并整合工作区现有水渠护栏；不重置其他对话修改。

## 造型与状态

上层出口仍在 `State.EXIT`，门架采用石座、榫接木梁、铜包脚、轴承、可动锁扣、纸轴与底杆；山、水纹章使用不同几何纹样。略向庭院转动 22.5°，在相机两端保留门洞剪影。真实中文标牌沿用思源宋体。

`paper_archive_gate.gd` 管理门体，不拥有寻路或解谜状态。双锚由真实 `upper_anchored && lower_anchored` 驱动：单锚仅点亮山纹；双锚首次成立后用 1.65 秒解扣、转轴、展开山水纸幕，中央逐渐通透。开启后维持稳定浅光和稀疏纵深刻线。没有全屏模糊、额外后方场景或粒子遮挡。

`baseline()` 在新建、读档和重开时同步既有状态，不补播开启动画或音效。暂停沿用房间与演示的现有处理；演示加速时门体按实际时间展开。真实到达仍使用原来的出口位置和 0.35 距离，新增“展开完成”保护，防止人物提前站在出口时跳过动画。没有扩大归档触发区。

任务改为“返回上层归档”，点击定位提升构图中心以展示完整门架；不传送人物，不在正常玩法中强制抢镜。完整演示在双锚成立后观察上层归档门，等实际展开完成再继续既有楼梯和归档路线。原完成画卷缩成锚座旁的小题签，保留“瓯江孤屿”文字。

## 素材与声音

`assets/paper_mill/archive_landscape.svg` 是本次代码绘制的局部山水矢量图，无烘焙文字。作为纸幕 UV 材质进入真实 3D 场景，随透视、角度和遮挡变化。`paper_archive_scroll.gdshader` 提供淡纤维、轻微起伏和中央透明窗口；只作用于一张局部门面，不采样屏幕背景。没有新增外部素材或网络下载。

木材和石材复用纸坊已有纹理；音效复用现有 `resonance_v01/clamp.wav` 与 `sfx/fold.ogg`，按 SFX 通道和既有音量设置播放，纸张声降低至 -29 dB，音高保持 1。静态门架复用现有网格合批，卷轴、底杆与锁扣分别保留可动节点。

声音设置中的“动态画面”开关将偏好保存在现有独立设置文件的 visual 分节，不影响故事存档。关闭时门使用约 0.18 秒静态淡化，不播放完整展开动作和机构声音。启动界面的原有动画实现未改。

## 验证入口

新增 `--paper-scroll-gate-check` 运行原生 Windows 视觉与功能检查，覆盖门态、单锚、展开、暂停、恢复、低动态、三种倍率、旋转端点、窗口与全屏、输入坐标及实际人物移动触发。视觉状态截图使用明确的布景夹具；真实双锚、通关与归档另由原有完整流程和完整演示回归覆盖，不把布景夹具当作真实通关。

`--paper-scroll-gate-check --gate-record` 从真实第二关初始状态启动生产完整演示，记录双锚成立到观察局回程；没有直接摆放镇纸或写入完成标记。原生 `--write-movie` 输出再转码为 MP4，不以插帧或效果图代替行走。

同机位前后截图、最终导出程序报告和录像位于 `showcase/checks/scroll-gate-v01/` 与独立试玩目录。最终数量及检查限制以随包验收报告为准。
