# 归档回收 · 通关返回大厅 v0.15

2026-10-21。采用确认的第四方案：观察局“归档回收”。只在真正通关、进入归位门时触发；普通“返回机构”按钮继续直接返回。

## 表现与时序

1. 衍月最后迈入修复后的归位门，约 0.14 秒淡出；场景冻结，关闭人物与机关操作。
2. 校准室实机画面缩成带黄铜细边的奶油色档案卡。画面来自当前视角的独立截图，不包含任务和操作 UI；每次重玩重新取图。卡片保留地图名称、完成锚点数量与递增编号。
3. 约第 0.68 秒落下“校准完成”印章，带短促缩放冲击与盖章声。
4. 约第 1.16 秒卡片缩小并滑入右侧档案柜，配纸张滑动声；随后显示“异常空间，已收好。”和归档确认声。
5. 第 1.58 秒在遮罩下换成接待大厅，至 1.95 秒完成淡出。大厅标题此后开始计时，衍月淡入并向前走两步，玩家立即可接管。

卡片动画共 1.95 秒，加进门前奏约 2.1 秒。沿用现有配色、字体和代码绘制图形，无需新视频资源。背景音乐跨场景连续播放；过场期间 M 键仍可静音。

## 实现

- `archive_return.gd`：独立 CanvasLayer（100），档案卡、盖章、入柜、淡出和三个音效节点。拦截过场输入，避免玩家重置或误点击大厅按钮。
- `game_flow.gd`：完成事件去重、冻结旧房间、复制已渲染画面、遮罩下切场景、释放过场。普通返回不触发成功动画。
- `tutorial_hub.gd`：短暂入场淡入、足下余光和安全位置上的两步行走；入场时可用 WASD 接管。
- `bureau_audio.gd`：复用随包 CC0 的 Kenney 音效，运行时调整音高、音量作为盖章、滑动和归档确认。音乐播放器保持同一实例。退出前等待音频线程释放，兼容加速测试。
