# 第一关满构图背景与整合提示词 v01

用途：第一关“新手校准室”的美术设计与后续游戏整合。本轮只制定提示词，不生成图片、不修改关卡。

## 一、场景概念图主提示词

为游戏《世界不按说明书》的第一关“新手校准室”设计一张高完成度的2.5D室内场景概念图。

参考图角色：以刚完成的接待大厅实机截图作为美术风格、材质、光照、人物尺度与满屏构图参考；以当前第一关实机截图作为机关位置、通路与高低关系参考。最终效果应让玩家感到：从同一座平行宇宙观察局的接待大厅，进入了其内部的专业校准实验大厅。

【视觉风格】
保持接待大厅的半写实绘制质感、正交斜俯视、精细材质与明亮室内照明。象牙白石材、深蓝金属、少量胡桃木和低饱和香槟黄铜构成统一视觉语言。墙面有真实的凹凸层次、嵌入式构件、接缝、倒角和细腻磨损，金属反射克制。环境有空间厚度和接触阴影，避免简单几何体、平涂墙片、塑料玩具感。实验室保留接待大厅的精致建筑语言，以仪器、维护柜和导轨设备取代大量休息室家具。

【镜头与满屏构图】
采用与现有关卡投影匹配的正交斜俯视视角，地面两个轴的斜率约为正负1:2；不要广角、鱼眼或明显的透视消失点。按当前1280×800游戏视口的8:5比例组织画面，素材分辨率可等比例提高。
建筑与地面持续延伸到画面之外。顶部、左右边缘由连续立面、舷窗、仪器墙、墙柱和地面自然充满；下方地砖延伸出画，不露出一个完整菱形底座。环境细节集中于两侧和后方，中央操作区保持开阔、清楚、有足够行走余地。画面可以饱满，但不能靠杂物堵塞通路。
仅通过视觉外围延伸、立面补全和经过投影校验的镜头构图调整实现满屏，不擅自扩大当前可行走区域。

【空间分区】
后侧为精密校准仪器墙：象牙白饰面、深蓝嵌柜、黄铜边框，结合机械刻度盘、玻璃仪表、整齐收纳的小型观测设备与柔和工作灯。设备嵌入墙体，避免随意堆放巨大的装饰机器。
侧方设置大型深嵌式宇宙舷窗：厚金属窗框、少量玻璃反光，窗外可见有层次的星海、远处行星与很淡的观测轨迹。窗外宇宙是室内的远景，亮度和细节弱于中央机关。局部可以保留校准舱外层玻璃弧线和结构锚接的暗示，但不能让密集球壳线条穿过中央解谜区。
前侧避免高墙与遮住角色的立柱，以连续地面和低矮建筑细节交代空间。装饰性墙柱、线槽、仪表、维修构件都应位于现有通路之外，并有合理的支撑关系。

【解谜舞台与视觉层级】
严格保留当前第一关的空间关系：镇纸初始位置与导轨起点、导轨中段挡块和星位机关、导轨末端升降结构、上方月痕印座、下方封界踏板、右侧归位门，以及玩家出生区和导轨两侧的操作通路。
中央长导轨是视觉中心：深蓝嵌槽、成对导向轨、细密横枕、黄铜紧固件与浅色陶瓷边饰，有真实厚度，但整体低矮。起点、中段和末端有可辨认的机械结构，不画文字解法或连续箭头。
星位机关采用克制的星形符号及环形刻度，突出真正需要镇纸作用的踏板。
月痕印座使用月牙标记，上方印座与下方承载区在同一机械框架中对应，立柱上的细刻度强调高度关系，不能被背景仪器混淆。
封界踏板具有独立的裂隙闭合符号，与右侧归位门存在细而清楚的能量连接。归位门采用与大厅同系列的深蓝金属、象牙白饰板和黄铜结构框，门洞轮廓完整清楚。
镇纸、活动挡块、升降部件、压力板状态、发光符号和门内裂隙均为后续独立可动对象；概念图中的表现仅用于定位示意，实际背景底图不得把它们画死。

【光照与可读性】
整体明亮，象牙白地砖保持干净的暖灰与浅米色层次，避免发白过曝。宇宙窗带入柔和冷光，仪器灯提供少量暖光。人物、镇纸、轨道与踏板拥有清楚轮廓；不要用强光、反射、浓雾、杂乱管线或复杂花纹淹没它们。地面纹理比机关安静，关键机关的对比度高于外围装饰。
保留左侧功能UI、左下目标区及底部对话区的阅读空间：这些区域仍画完整环境，但背景细节适当收敛，不把唯一的重要机关藏到UI下方。UI由游戏实时显示，图片内不生成按钮、任务文字、标题或水印。

【三个平行世界】
三种状态共享完全一致的建筑几何、机关位置、人物比例与镜头。保持观察局室内美术统一，通过局部材质、色光和环境动态体现不同规则：
冰晶世界：冷白与浅青，导轨边缘逐段结霜，清晰可见的薄冰、白霜和少量细小冰晶，冷雾轻微，不覆盖镇纸、挡块、星位与刻度。
重力世界：柔和琥珀色工作光，家具和设备底部接触阴影略重，底脚附近可出现细小受压裂纹与少量落尘；地面保持完整可行走，不出现真实深坑与新增障碍。
倒悬世界：淡紫与冷蓝，少量纸片、微尘和轻小碎屑向上漂浮，细光粒强调向上的方向。大厅建筑、人物站姿和操作坐标保持稳定，不将整张图翻转。
同一处背景细节可在世界切换时改变状态，但不能因此产生假的道路、隐藏真实踏板或改变碰撞边界。

【避免】
完整小型菱形房间、孤立浮岛、整圈可见底座、四周纯色空白、杂乱宇宙背景直接包围地板、廉价平涂墙、重复复制的巨大装饰件、雪村和部落元素、赛博朋克霓虹、过暗画面、过曝金色、夸张透视、错误的等距方向、装饰遮住主角头部、无处可走的狭窄通道、额外机关、额外出口、明显解法箭头、图片内人物、UI和乱码文字。

## 二、落地资产拆分提示词

概念图通过后，按同一美术标准拆分素材，不把完整概念图直接铺在所有游戏对象前面：
1. 干净的石材地面与可平铺纹理，不包含镇纸、轨道、影子、按钮和文字。
2. 后侧仪器墙和侧方宇宙舷窗立面，以适合映射现有关卡真实几何的正视立面输出，不能把斜视概念图直接拉伸贴到墙上。
3. 壁柱、嵌柜和前景构件按实际需要独立分层；透明素材保留真正的alpha通道。
4. 镇纸、导轨、挡块、月痕结构、踏板及归位门继续使用独立实时对象；允许更新外观，不替换其运动与状态逻辑。
5. 冰霜、受压裂纹、上浮纸屑、机关高亮及能量连接分别保留为可控制的动态层。三世界不使用三张位置不同的随机生成地图。
6. 所有素材统一材质尺度、光线方向、纹理精度与接缝；近景构件按现有深度系统正确遮挡，避免贴图悬空或人物穿墙。

## 三、游戏整合约束提示词

本次目标为第一关背景与场景美术升级，现有功能是不可牺牲的验收条件：

- 当前可行走范围、出生点、镇纸轨迹、导轨起终点、挡块、星位机关、月痕印座、封界踏板和归位门的逻辑位置保持。
- 保留冰晶低摩擦运送与两处反向回滑、重力压住机关、倒悬上浮接触印座及原有机关顺序；已完成状态的保留方式不变。
- 保留WASD与点击地面移动、右键/E就近互动、角色接近与伸手推动动作，以及导轨两侧就近操作。
- 保留1/2/3切换世界、1.5秒共享冷却与胶片错位重合过渡；不恢复Q切换。
- 保留左Alt＋左键拖动约正负45度旋转视角及当前鼠标方向。背景建筑必须支持随相机正确投影，不能在转动时变成固定贴纸、露边或产生明显错位。
- 保留实际碰撞、寻路避障、角色头部与建筑遮挡处理；场景中看似可走但不可走的位置要有明确的建筑边界。
- 保留主任务与当前阶段目标、任务悬停时对应最终互动踏板的高亮、分级H提示、NPC对话与世界规则教学；背景不能提前画出全部解法。
- 保留星位/月痕反馈、约一秒封界收尾、归位门开闭、通关纸页归档、裂隙出入场、返回大厅，以及现有音效与音乐。
- 不把美术升级变成新关卡设计，不额外增加玩家必须完成的步骤。
- 修改后验证默认和左右极限视角、三个世界、导轨两侧互动、两处回滑、月痕高度与末端踏板识别、实际通关、归档返回，以及UI和角色遮挡。
