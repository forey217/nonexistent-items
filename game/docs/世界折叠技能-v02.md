# 世界折叠技能 v0.2

2026年10月20日，用户要求切世界有动作、技能UI位于左上角、内置3秒CD。

动作采用单手向前轻划，身体微倾，脚下等距折叠环向外展开，三角纹和少量晶片围绕角色升起。四个朝向复用已校准的手臂挂接与遮挡；不修改人物原图，不新增图片。视觉由Godot分件姿态与绘图完成。

施放持续0.55秒，在0.22秒时切换目标世界并应用新的物理规则。施放中暂时站定，取消原路线和待执行推动，结束后恢复移动和交互。物品物理与机关继续运行，不暂停整个世界，也不移动衍月的位置。

技能面板在左上角，包含Q图标、当前世界、下一个世界、三个定向切换小按钮。圆形恢复遮罩和0.1秒精度数字显示共享冷却；原任务面板移到左下空白位置。

冷却从接受施放请求开始计3秒，包含施放动作时间。鼠标图标、Q键、1/2/3键和小按钮统一通过同一请求入口；冷却中全部拒绝，不排队、不延长计时。点当前世界或无效目标不消耗CD。初始与重置后就绪。R会取消尚未完成的施放、清空特效与冷却。完成手势后，移动和推动不受剩余CD影响。

新增模块：`scripts/world_skill_button.gd`绘制技能图标/恢复遮罩，`scripts/world_switch_fx.gd`绘制角色周围特效。动作强度由`yanyue_walk_rig.gd`的cast_amount控制；移动组件在施放期间保持脚底碰撞且不跟随路线。
