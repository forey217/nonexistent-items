# 步态 v0.3 自检与修正

2026年10月20日。用户指出手臂、腿部不自然，步频过快，背向时手臂异常。

## 确认的问题

- v0.2背向图的近侧肩在右边，却复用了正面近侧肩在左边的位置。加上近侧袖子绘制在身体前方，会出现错误的前后遮挡。
- 袖子用统一缩放和不准确的旋转中心，粗细、长度和肩部贴合不合适，正面袖子自身倾斜也没有校正。
- 髋位置和脚部站立落点左右不对应，站立也可能交叉。原二段骨骼解算在接近站立时仍强制弯膝，腿形不自然。
- 原移速185像素/秒、完整周期110像素，即每秒3.36步；步幅、屈膝、摆臂同时偏大。

## 修正

- 正面与背面分别设置近侧/远侧肩的位置、袖子源图挂接点和自然垂落角。背面近侧袖子挂右肩并处于身体前方，远侧挂左肩并处于身体后方；镜像生成左朝向。
- 各袖子分别匹配肩部宽度和长度，挂接点位于袖子肩帽内部，避免肩头脱节。
- 站立时两个脚部落点与各自髋的左右顺序一致。膝盖靠近髋与踝的连线，仅在迈步时作轻微偏移；不再强制大幅屈膝。保留平行纹理切片，避免腿部网格折叠漏绘。
- 移速185→145像素/秒（下降约22%），完整左右脚周期110→180像素，步频3.36→1.61步/秒（下降约52%）。单侧前后摆幅27.5→18像素，抬脚7→3.2像素，手臂摆动幅度0.43→0.12弧度。
- 摆臂相位与对应腿的前后位置匹配；身体起伏与前倾减小。受阻时停止推进，保留0.1秒起停过渡。

未修改生成图片像素，没有新生成图片；继续使用`assets/yanyue_rig_v02.png`，调整均在Godot组件内完成。

## 验证

先用同一动画组件录制四个朝向、行走4秒与停步1秒的原生渲染视频，检查起步、相反脚前伸、经过站立、背向及停步截图，再检查导出程序。

自动检查包含：正面/背面肩部左右关系、前后遮挡顺序、站立双腿顺序、背面双手在整轮32个相位中不横穿背部中央、步频范围、整轮网格可渲染、连续移动、起停、鼠标绕行、手动接管及原墙体/家具碰撞。

73项检查通过；最终导出结果另存于发布目录的`移动检查报告.json`。书架一侧因相邻陈设妨碍测试起点摆放，仍在报告中列为未单独接近测试的方向。自动检查能验证这些约束，不能代替对动作观感的人工检查。
