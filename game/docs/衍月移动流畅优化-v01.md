# 衍月移动流畅优化 v01

覆盖接待大厅、新手校准室与纸山叠影。沿用现有人物素材、碰撞体、自动楼梯和存档格式。

## 最终参数与行为

- 最高速度保持 174 逻辑像素/秒。
- 普通起步 0.10 秒达到全速（加速度 1740 像素/秒²），首个物理更新即产生位移。
- 普通松键以 0.08 秒从全速刹停（减速度 2175 像素/秒²）。60Hz 验证从全速松键后移动约 5.56 像素，30/120Hz 分别约 4.35/6.25 像素；差异来自离散物理步进，未声称不同物理频率下逐像素完全一致。
- 点击寻路终点使用剩余距离和制动距离计算目标速度，到达半径 0.45 像素；只在最终目的地完成时发送一次抵达事件。
- 明确反向时立即按新方向移动，降低瞬间反向的速率后快速加速，不先向旧方向滑行。
- 键盘接管点击路线只清理路线，保留当前运动速率与脚步相位。公开取消、剧情锁定和窗口失焦立即清除普通速度。
- 普通拐点最多提前约 17.4 像素观察下一段。通过现有完整角色宽度的扫掠/纸坊通行校验才允许提前转弯；护栏、楼梯触发区域和其他不可达区域依旧受约束。

## 动画与显示

步态继续由真实位移推进，普通停止不再清空累计距离。摆臂、抬脚与轻微前倾随实际速度变化，步态权重在约 0.14 秒内收回站姿。碰撞挡停后按真实移动量停止脚步。

朝向使用归一化方向约 0.14 的分量稳定区（约 8°），过滤靠近轴线的小幅抖动；明确转身、剧情面向和脚本楼梯朝向优先处理。二维与三维贴片共用朝向选择方式，三维先投影到当前镜头再判断。

人物画面与影子在相邻物理位置之间按画面时间插值，逻辑碰撞与交互仍使用真实位置。显示最多落后约一个物理步（默认 16.7ms），不增加额外长时间跟随。大厅及纸坊跟随目标使用同一显示位置。传送、重置或读档清空旧插值状态；楼梯和入场保留原脚本运动。

## 验证与对比

专项入口：`--movement-smooth-check --artifacts=<目录>`，55 项实际输入/位移/碰撞检查；覆盖 30/60/120Hz 物理步进、短点、反向、松键、抵达、接管、连续换目的地、桌角绕行、锁定、失焦、暂停、镜头方向、影子与楼梯出口。

视频入口：`--movement-smooth-demo`，可附加 `--comparison-before` 标注原版。Godot Movie Maker 以 60fps 记录真实场景和输入驱动的画面，前后使用同一脚本时序、场景、地图与素材；仅移动、步态和对应显示实现不同。双屏对比的左侧为优化前，右侧为优化后，没有用重绘画面替代游戏。

原有 73 项移动/碰撞检查保留；调整旧测试对“松键立即静止”和“不同速度固定帧数必定同位移”的假设，改为验证短刹停与步态累计距离确实等于实际行程。没有放宽墙体、家具、角落、寻路或高速扫掠的安全断言。

图形程序分别以 30fps 和 120fps 固定帧步进执行专项，另回归楼梯朝向、护栏、两关完整解谜、存档和剧情。固定步进检查与 Movie Maker 录像均不作为设备实时性能成绩。
