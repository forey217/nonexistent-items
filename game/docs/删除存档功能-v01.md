# 存档界面删除记录

每张已有记录（包括损坏记录）的右上角提供 34×34 的细线垃圾桶按钮，随卡片旋转，悬停提示“删除记录”。点击只打开确认框，不进入游戏。空档位隐藏按钮，整张卡片仍可点击进入或新建。

确认框使用现有象牙白档案纸、黄铜切角边框、深蓝宋体和暗红操作按钮。显示固定目标编号、真实地点、进度、最近保存时间及不可恢复说明。损坏记录显示“记录无法读取”。背景不可操作。默认焦点为“保留记录”；Esc 取消，左右方向键或 Tab 切换，Enter/空格执行聚焦项。也可在存档选择界面按 Delete 删除当前选中记录。

确认删除后，清理指定档位的 `.json`、`.json.bak`、`.json.tmp`。若该档位是最近使用记录，将最近使用档位调整为其他有效记录。清除对应活动档位的内存状态，阻止自动保存写回。其他档位和全局选项不变。

删除前读取待操作文件快照，遇到读取、删除或最近档位写入失败时尝试回滚，确认框报告失败，不提前清空卡片。成功后约 0.25 秒淡化刷新单张卡片，显示“存档 NN 已删除”，保留当前布局和背景动画进度。取消与完成删除后有短暂输入隔离，避免同次点击穿透。

相关实现：`save_book.gd`、`save_select.gd`、`save_record_card.gd`、`save_delete_dialog.gd`、`game_flow.gd`。

专项验证：`tests/save_delete_checks.gd`。必须提供隔离的 `--save-dir=绝对路径`，使用 `--save-delete-check --artifacts=输出目录`；第二次启动附加 `--save-delete-reopen` 检查删除记录不会恢复。覆盖损坏记录、备份与临时文件、部分删除失败回滚、元数据失败回滚、其他档位及音量设置不变、鼠标与键盘、默认取消、弹窗输入隔离、活动记录清理、卡片进入及删除后新建。
