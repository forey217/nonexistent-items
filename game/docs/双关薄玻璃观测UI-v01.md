# 双关薄玻璃观测 UI v01

本次在现有工作区上改造关内材质，保留三世界校准室、纸坊双层四规则、逐句配音、楼梯自动行走及防折返、楼梯护栏、清晰度与相机适配等已有实现。启动背景、星系仪推进和存档选择不参与本次材质改造。

## 公共样式

`instrument_theme.gd` 管理字体、文字色、按钮状态、材质入口及通讯排版。`instrument_glass.gd` 是一个小型 StyleBox 资源：以九个顶点渐变四边形建立正文衬底和通透边缘，加短反光、局部铜线、角标和低强度细纹。没有图片背景，没有屏幕纹理读取，没有模糊或新的离屏视口。普通控件继续使用 Godot 原生字体、输入和键盘焦点。

第一关以暖烟灰 `#3D423C` 为起点，普通正文衬底不透明度为 0.86，菜单 0.90；第二关以灰绿 `#304139` 为起点，普通衬底实际为 0.905，菜单 0.925。边缘在各自正文强度的 86% 附近柔和过渡。细纹只有 0.008 的强度，固定 9 个逻辑像素间距；线宽固定一个逻辑像素，不跟地图缩放变化。

正文为 `#E7E2D4`，次要文字为 `#ADB8AE`。装饰铜线保持 `#B39A69`；实机比较后将小号铜色标题单独提亮至 `#D0BB8D`，避免明亮石材透过面板后降低小字对比。正文不靠降低透明度表达轻盈。

## 面积和层级

- 第一关任务区高度由 88 减至 78，当前目标字号仍为 22。
- 第一关三规则共享一个托底，取消三个独立描边方框；当前世界仍有定位点和铜色下划线，真实冷却环、禁用和键盘焦点保留。
- 第一关短反馈由 700×72 改为默认 520×46，重复错误不续时；长反馈按内容增加高度。通讯占用时隐藏反馈。
- 第一关通讯由 820 宽改为 700 宽，按实际字体行高使用 96 高的托底，小头像、铜色姓名、两行 20 号正文。第二关保持 720×90 的紧凑通讯区域和 19 号正文。
- 第二关继续保持边缘 HUD、双层规则条、三枚状态项、直接召回、H 记录、侧边止挡和暂停菜单的布局。
- 两关记录、规则说明、暂停、确认和关内声音设置共用材质。标题界面使用的纸张设置页仍通过默认 `instrument_mode=false` 保留。
- 第一关游戏流程额外绘制的保存通知也改用玻璃材质，并避开通讯、暂停和普通反馈；纸坊继续使用自身的小型保存反馈。

## 通讯与交互

通讯使用真实字体的 TextParagraph 测量宽度后分页，保留全部原始文本。人工换行保留；在一行只剩极少汉字时，优先在标点处平衡两行。分页结果仅在收到通讯时计算并缓存，不在每帧重新排版。配音 ID 与原文不变，显示时长至少覆盖每页阅读时间，暂停沿用原来的语音和计时暂停。

没有通讯时隐藏完整父区域。透明装饰由 StyleBox 绘制，不增加输入节点；现有按钮与实际面板仍拦截输入，地图坐标、世界视口和角色视口不由这次材质改造重设。

## 验证入口

新增 `--glass-ui-check --artifacts=<绝对路径>`，以真实图形程序检查两关通讯完整性和行高、材质变体、反馈去重、控件状态、窗口与全屏、纸坊两层三个倍率及地面坐标，并保存实机 PNG。现有 `--instrument-hud-check`、`--dialogue-check`、`--paper-story-check`、`--save-check`、`--paper-mill-check` 和 `--paper-guardrail-check` 继续用于实际流程回归。

最终 Windows 包附带原始结果、同场景前后截图和本轮检查报告。报告明确区分图形程序与 headless 辅助回归，不将固定步进测试当作实时帧率成绩。
