# 黄铜星仪环门入场 v0.42

采用已选第一方案“星仪环门”，替换原简易蓝色多边形裂隙。现有角色外观、骨骼分件及走路动画保留；没有把概念图或人物烘焙成整张背景。

## 视觉与动画

三道具有不同倾角的黄铜轨道，带金属明暗、细边、56组刻度和小型蓝色玻璃星珠。中央使用项目已有星海纹理与独立着色器，缓慢漂移并叠加星点和细星座连线。门体高约200像素，脚下为细金色椭圆观测环、刻度和局部柔光；没有实体台阶或大底座。

完整入场2.15秒：0～0.3秒地面定位；0.26～0.7秒轨道旋开、星空门面展开；0.66～1.08秒人物显现，0.72～1.43秒沿真实安全通路迈出；1.45～2.02秒门面及轨道合拢，光环和星点到2.15秒结束。角色走完后保持完全可见，通道关闭不带走角色。

大厅保留首次抵达的站稳节奏，重复抵达略加快环门播放。入场期间锁定人物和返回主界面入口，结束后恢复自由走动、桌前光标与首次操作提示。菜单、选档、原剧情及完成关卡后的归档回大厅继续保留。

## 分层与适配

`spatial_rift.gd`绘制前、后轨道和地面光环，`armillary_aperture.gdshader`负责星空门面；时钟由入场控制器驱动，视觉不单独累积时间。前景轨道限定在肩部以下，避免横穿面部。

大厅前后层作为独立节点加入同一Y排序场景，角色迈步后自然走到前层之前。校准室与纸山地图使用`armillary_billboard.gd`的双透明视口和真实场景坐标，通过深度测试与明确的透明绘制顺序保留人物轮廓；随相机位置更新朝向。修复了半透明地面光晕被Alpha裁切成黑边的问题。

校准室结束后同时隐藏前后Sprite并将两个视口设为UPDATE_DISABLED；大厅和纸山的临时节点释放。复位或切场景时同样清理，避免残留渲染。
