# 接待大厅星系仪开场引导

首次开场故事完整结束或通过 Esc/跳过按钮结束后，角色恢复操作，等待 0.4 秒唤醒星系仪。直接切换场景、关闭流程、普通提醒对话不会触发唤醒。对话过程中保留原有装置表现。

唤醒约 1.2 秒，依次增强星核、轨道和底座光纹，播放一次低音量星铃。亮起后保留轻微蓝金呼吸光（周期 3 秒）与少量局部星点。底座范围内提供柔和映光，结束阶段扩散一次小光环，无全屏遮罩，无新增碰撞和输入拦截。

唤醒完成时在装置上方显示“前往星系仪，开启观测”，使用深蓝思源宋体、浅金描边，约 3 秒后淡出。提示跟随大厅摄像机，并限制在屏幕内。鼠标悬停提示与此文案避免重叠，保留原点击及靠近按 E 的交互方式。

实际创建并打开世界选择界面后，标记引导完成，局部光效约 0.5 秒恢复基准亮度。世界选择界面暂停大厅期间，仅让该局部光效完成淡出。被对话或其他状态阻止的交互不标记完成。

每份存档增加两个可选故事字段：`globe_awakened`（首次唤醒已触发）与 `globe_guided`（已成功打开世界选择）。完成引导后返回大厅、跨场景或重新启动不重播；已唤醒但尚未操作的存档只恢复稳定呼吸光，不重播动画、声音与短文案。旧存档允许缺少这两个字段：已看完开场的大厅记录只恢复稳定引导；已经进入关卡或完成过校准的记录视为完成引导。删除活动存档时同时清除这两个内存字段。

实现：`bureau_dialogue.gd` 负责对话收尾；`globe_atmosphere.gd` 与 `globe_core.gdshader` 负责光效；`tutorial_hub.gd` 负责位置与提示；`game_flow.gd`、`save_book.gd` 负责持久化和完成条件；`bureau_audio.gd` 负责单次星铃。

验证：隔离存档运行 `--globe-guide-check --save-dir=路径 --artifacts=目录`，27 项覆盖正常与跳过、延迟和分阶段、自由移动、提示消退、单次声音、失败操作、菜单暂停下淡出、返回大厅、独立档位与旧档兼容；再次启动附加 `--globe-guide-reopen` 验证完成与未完成记录的持久化。
