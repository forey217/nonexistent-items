# v0.28 玻璃锚接支架

范围仅限新手校准室；接待室美术与布局不变。

在平台四个侧面锚位连接外部玻璃球壳：双梁支架、带螺钉关节、内置伸缩杆、黄铜加强套。平台端使用实时相机投影；玻璃端与既有椭圆球壳求交，左右旋转时保持连续衔接。

球壳接点加入小范围椭圆压痕、穿入玻璃的金属销与五组分叉裂纹。深色裂缝边缘叠加细亮线，避免整片玻璃破碎的观感。

支架绘制于场景后方、平台可行走边缘以外，侧壁自然遮住根部；不遮挡人物与镇纸，不新增可点击机关，不扩展可走区域。细光带跟随三个世界色彩平滑变化。

全部为代码绘制，无新下载素材。玩法和冰世界末端回滑保留。

验证包含教程逻辑与通关回归、默认/左右45度与不同世界的原生截图检查，以及导出程序旋转视角完整解谜检查。
