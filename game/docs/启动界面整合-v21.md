## 实际流程

正常启动 → 插画启动界面 → 开始旅程 → 接待大厅 → 星系仪 → 水晶选关 → 裂隙入场 → 校准室。

通关仍按原有封界、盖章、抛物线归档与大厅裂隙出场执行。

启动界面中的 1/2/3 或三个世界按钮仅切换规则预览，不作为关卡或起始世界选择。正式校准室仍从冰晶世界开始。

开始旅程使用原有 0.45 秒淡出，并接 0.3 秒大厅显现，防止黑屏后硬切。双击不会重复进入。
F10 可从大厅或正常玩法返回启动界面；选关打开、切场景、裂隙入场与归档期间不打断过渡。

## 操作、音频与退出

操作手册移除 Q，说明 1/2/3 切换与 1.5 秒共享冷却，并补上大厅星系仪入口。
手册打开时遮挡背景输入，Esc 合上后恢复按钮焦点。
启动界面独立提供共享声音按钮；M 静音状态和同一音乐播放器贯穿场景。
F11 切换全屏；退出游戏经过统一音频释放流程。
