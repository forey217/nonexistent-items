# 人物步态 v0.2 美术与生成记录

2026年10月20日。使用内置 image_gen 工具，未使用 API/CLI 模式。

输入：用户认可的《不存在的物品-统一风格样张-v01.png》，用于角色身份、服装和画风参考。

正式素材：`game/assets/yanyue_rig_v02.png`（1254×1254，RGBA）。图中包含正面与背面三分之四视角的身体、近侧手臂、远侧手臂和完整腿部，共8个独立部件。左右朝向由游戏内镜像实现。原始图片完整保留，未用 Python 改图。

原始生成图保留在本地美术归档；本工程中使用的文件见下方素材说明与`assets/`目录。

`tools/inspect_rig.py`只读取透明度连通区域，输出 `assets/rig_layout.json`，不修改像素。实际区域按连通部件识别，不假定插画严格落在等分网格内。

Godot 运行时以图集区域和分段纹理网格组装人物，独立控制两腿、屈膝、脚的接触/摆动阶段与双臂。步态连续插值，并非32张已经绘制的动画帧；调试里的16个相位编号仅用于检查整轮循环覆盖。每110像素实际移动完成一轮左右脚循环，受阻时停止推进，视觉姿态在0.1秒内收回站立。膝盖/踝部的底层关节遮片用于避免纹理折弯边缘漏缝。

先前两次完整走路帧图集的试作中，左右腿交替仍不够清楚，因此未接入游戏。v0.1原素材保留，v0.2发布包不使用它。
