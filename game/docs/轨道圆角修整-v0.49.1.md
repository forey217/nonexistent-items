# 轨道圆角整合 v0.49.1

已验收快照 20261023-03，以轨道转角整合 v0.49.0 为基础。

## 本次修改

六处双轨弯道改为紧凑的同心圆弧，直轨在圆弧切点衔接；真实 T 分支的两个入口肩部也改为圆角。每段弧轨使用 16 个细分面。弯道下方改为扇形木枕，连接片和铆钉移到切点旁，保留原有旧铜和浅色金属材质。

中心参考半径 0.45，内轨半径 0.18，外轨半径 0.72，双轨间距仍为 0.54。采用紧凑半径，让原逻辑站点保持在两轨之间；镇纸按原有模拟移动与停靠，本次不改其运动路线与速度。未新增碰撞体，机关、谜题、存档和桥／吊台的显隐接驳沿用上一版。

另一对话中的新推动交互仍属独立制作范围，本包继续使用上次已验收的推动行为。共享工程中保留两项修改，本包对应完整封存工程在同目录 ZIP。

## 验证

Windows 原生图形程序共 7 组 582 项通过：圆角轨道 53、菜单 79、吊台 33、显影旧廊 115、推动与存档 170、完整通关 128、重启续玩 4。

弧轨检查包含实际生成网格的圆弧形状、直弧接缝、原站点位于双轨之间、真实连接范围、桥梁显隐与吊台接驳。实机拍摄上下两层 -45°／0°／45° 与 0.55／1.0／1.6 倍率，共 18 个画面；另检查典型弯道和动态装置。原始报告与截图见 showcase/checks/rail-rounded-v0491/。
