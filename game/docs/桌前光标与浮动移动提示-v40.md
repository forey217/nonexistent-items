# 桌前光标与浮动移动提示 v0.40

移除大厅原有两处引导：特斯拉上方的“靠近或点击交谈”框，以及左下角的移动、星系仪选关和交谈说明条。特斯拉悬停时也不再显示文字框。

初见交谈改由桌前地面的光标引导：细金色椭圆观测环、刻度、缓慢旋转的浅色弧线和轻微起伏的蓝金菱形。光标使用场景坐标，随大厅镜头移动，位于家具碰撞外可行走的地面，并在特斯拉的交谈范围内。点击光标会通过现有寻路走近特斯拉，接近后触发初见；直接点击特斯拉及E交谈保留。对话开始后移除光标，未完成入场时不显示。

移动提示在1280×800画面的底部正中浮现，不使用底框。思源宋体配深蓝墨色、淡象牙色细边、黄铜切角W/A/S/D键位、金色菱形与仪器分隔线，文字为“WASD 移动 · 鼠标左键 点击地面”。提示不拦截鼠标。

恢复操作后约0.7秒淡入；首次WASD/方向键操作或鼠标左/右/中键点击后约0.85秒渐淡消失。同一大厅中不因等待、停止行走或复位再次出现。仅移动鼠标不会消除提示。入场期间的菜单点击不计入；剧情和选关字幕显示时，移动提示会让出位置。

实现：`hall_desk_beacon.gd`负责场景光标；`hall_movement_hint.gd`绘制字体与淡入淡出；`tutorial_hub.gd`负责可达位置、鼠标寻路和首次操作检测。原剧情、存档、星系仪和解谜流程沿用现有实现。

验证：Godot 4.7.2，Windows / ANGLE实机检查93项通过，涵盖可达光标、无框居中排版、仅鼠标移动不消失、WASD及鼠标点击渐隐、复位后不重现、光标寻路与完整剧情通关；菜单52项、三档存档48项通过，共193项。实机截图与检查报告随新版试玩包保存。
