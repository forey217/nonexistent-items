# 头部碰撞与贴墙修复 v0.5

## 原因

v0.4的角色纸片使用完全朝向相机的billboard，随相机30度俯角产生倾斜。脚底停在墙外，上半身却沿着倾斜平面伸入墙后，出现头部、身体被墙面截断。旧二维边界也未包含墙板、管道和窗框向室内突出的厚度。

## 修改

1. 人物改为仅绕Y轴朝向相机，保持世界中的竖直站姿。高度比例补偿俯角投影，维持原画面中的人物尺寸；脚底给出很小的深度余量，防止与地板共面时边缘闪烁。
2. 两面可见墙内侧增加0.42网格的实体占地，并将其同时加入点击寻路。人物停止距离覆盖墙板、管道与角色画面的横向轮廓。
3. 新增`yanyue_head_guard.gd`。头部为真实的`CharacterBody3D + CollisionShape3D + SphereShape3D`，球心高度1.95世界单位、半径0.32，检测两面墙的三维实体包围体。F2显示半透明蓝色碰撞球，正常游戏不显示。
4. 二维人物移动前调用头部扫掠。碰撞后先移动安全距离，再沿墙面计算剩余滑动，最多处理三个接触；不是只有提示功能的重叠传感器。导航的通路检查也包含该扫掠。
5. 脚底二维碰撞继续处理地板边界、家具、轨道与门。头部检测只针对墙壁，避免把桌面等低矮物体当成整面高墙。

游戏从未关闭人物的深度测试来遮盖问题，正常物体前后遮挡保持有效。测试中的无深度参考只用于量化墙体是否错误截断人物，捕获后立即恢复正常深度。

## 验证

`--wall-self-test`包含真实头部球体、独立头部阻挡、沿墙滑动、高速扫掠、双墙转角、F2显示、墙体导航保护、实际行走触墙、贴墙后点击离开，以及12组原生渲染对照（两面墙、默认与左右45度、正面/背面/施法）。

渲染检查冻结姿态，比较正常深度画面、无深度人物参考及无人物背景，统计本应显示的角色像素是否被墙体截断。修复前可复现约70%–80%角色像素缺失；修复后的12组对照均未出现该截断。完整数据以构建附带的`wall-test-report.json`为准。

另保留原教程、视角旋转、人物移动检查，并在导出程序中实际通关返回观察局。碰撞球的扫掠报告验证其实际响应，不仅检查节点是否存在。

运行原生渲染检查：

```text
Godot --path <game目录> --fixed-fps 60 -- --wall-self-test --artifacts=<报告目录>
```

无图形的headless模式只执行物理部分，无法替代上述画面对照。
