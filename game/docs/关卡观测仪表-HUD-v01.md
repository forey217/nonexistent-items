# 关卡观测仪表 HUD v01

本轮把新手校准室和纸山叠影的关内 HUD 统一为墨蓝半透明底、细黄铜边、思源宋体和少量浅蓝选中光点。运行 `builds/关卡观测仪表-v01/世界不按说明书.exe`。

常驻布局只有左上任务、右上物性与菜单入口、下方世界切换仪表。第一关三个世界和第二关四个世界、两个观察层均使用实际逻辑，未修改任务阶段、切换条件或1.5秒共享冷却。菜单关闭后，空白界面区域继续允许地图点击。

## 任务与物性

第一关任务签只常驻当前阶段，悬停标题展开三项目标，悬停条目仍能照亮对应机关；点击任务可固定展开，Esc收起。任务进展读取真实机关状态，完成时显示短暂刻线标记。

第二关任务签保留七个实际阶段。悬停查看观测记录，点击固定展开；镇纸位置、留影夹状态、定位和召回操作收进记录。展开记录本身不会增加提示层数，H与“下一条提示”沿用原分级提示功能。

物性签默认仅显示当前世界的短说明，切换后约三秒展开规则，悬停可复看。镇纸状态在靠近或悬停时跟随物体出现。世界按钮的同一圈刻度来自同一个冷却值，无独立计时器。

## 菜单、设置与字幕

复位视角、返回机构、重置、提示、操作说明、声音设置和返回主界面集中在右上菜单。重置入口与R均先确认；第二关额外保留恢复稳定记录、完整重开本关两种实际功能。

声音和手册复用档案纸选项页，保留总音量、背景音、音效、对话语音四路设置；第二关手册说明1—4、Tab观察层、自动楼梯、缩放和平移等实际操作。Esc依次返回手册上级、关闭设置、关闭菜单，焦点返回对应入口。

菜单打开时人物与机关暂停；第一关正在播放的语音及字幕计时同步暂停。停止旧语音时清除暂停标记，避免返回主界面后新配音仍处于暂停状态。

关内非模态对白固定在世界按钮上方，主剧情时暂时收起不可用的世界按钮。进入关卡的精简操作提示只出现一次，首次有效移动或鼠标操作后约0.65秒淡出，不会重新弹出。对白和临时消息出现时隐藏低优先级操作提示。

## 验证与素材

新增 `--instrument-hud-check` 检查两关的点击拦截、冷却、重置确认、菜单暂停、四路设置、手册焦点、语音恢复及宽屏布局，并输出原生截图。当前原生31项通过；既有第一关67项、任务23项、对白93项、第二关操作36项和HUD流程19项通过。导出包另通过27项配音检查。

检查和截图位于 `showcase/checks/instrument-hud-v47/`。所有新增界面由引擎绘制，沿用现有字体，无新增栅格HUD素材。
