# 移动时井口闪烁修复 v0.55.1

第二关落物口、吊台井口边缘在人物移动、相机跟随时出现细碎条纹。Windows ANGLE 实机复现后，关闭阴影仍可见，因此没有通过关闭阴影解决。

原因是 `floor_mesh` 在两个井口周围使用完整封闭方块生成井壁。井壁方块的顶面和庭院地面同处楼层高度，且分别使用石材原色与规则染色材质，重叠区域产生深度冲突（Z-fighting）。

`shaft_lining` 现在保留井壁原来的侧面、底面、位置和材质，去掉被地面覆盖的重复顶面。上下层、两个井口同时修复；不更改碰撞、寻路、井口大小或机关状态。新网格仍由世界胶片按所在楼层注册。

楼梯及水岸护栏共享遮挡淡化逻辑：首次遮挡即开始渐隐，射线短暂失去遮挡后等待 0.16 秒再渐回，避免人物经过立柱边缘时反复切换透明度。完全恢复后回到不透明渲染，暂停时淡化不推进。

验证资料位于 `showcase/checks/movement-flicker/`。`before/shafts.png` 与 `after/shafts.png` 为相同机位修复前后截图；`after/shift*.png` 为连续小幅相机移动，另有上下层及左右旋转视角截图。专项检查覆盖真实网格中重复顶面的移除、护栏临界射线间断、暂停、恢复不透明及模拟状态保持；已有楼梯、水岸、相机及胶片检查报告保存在相应子目录。

独立程序为 `builds/移动防闪修复-v0.55.1/世界不按说明书.exe`，由 `.artifact_work/movement-flicker-v0551/game` 的固定快照导出，标识 v0.55.1 · 20261024-07。共享工作区原有改动保留，旧版程序保留。

最终验证：6 组、454 项通过（含导出包 57 项回归）。胶片检查使用真实时间实机运行；早期固定帧率无窗口试跑不能用于墙钟动画时长断言，最终结果见 `film-native/paper-film-report.json`。
