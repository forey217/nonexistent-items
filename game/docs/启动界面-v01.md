# 世界不按说明书 · 启动界面

默认启动进入原生 Godot 菜单。左侧使用象牙白、深蓝字体及金色细线。右侧 v0.2 改为衍月身处平行世界入口的完整 2D 插画，移除了旧版台座、刻度圆环和独立人物骨骼。场景美术在 `assets/start_menu/parallel-worlds-v2.png`，提示词及来源见 `启动界面-v02-图像提示词.txt`。

## 已接入

- 开始旅程：淡出后进入现有新手校准室，防止重复点击创建多个关卡。
- 冰晶、重力、倒悬预览：鼠标点击或按 1 / 2 / 3，改变插画上的轻微色调、浮光运动与说明。三个世界的建筑同时呈现在同一张插画中，选择预览不会更换整张背景。预览不改变教程初始世界，教程仍从冰晶开始。
- 操作说明：打开手册，按钮或 Esc 关闭。
- 动态画面：开关当前菜单的浮光动画；插画本身为静态素材。
- F11：在菜单中切换全屏。
- F10：从教程或大厅返回菜单。返回后再次开始会重置教程，不保存关卡进度。
- 退出游戏：退出当前进程。

这是本地单机启动菜单，当前没有账号登录、注册、云存档或继续游戏。

## 入口与验证

场景：`scenes/start_menu.tscn`；脚本：`scripts/start_menu.gd`；流程：`scripts/game_flow.gd`。

现有 `--self-test`、`--capture`、`--capture-gait`、`--walk-demo`、`--tutorial-self-test`、`--orbit-self-test`、`--tutorial-demo`、`--hub` 参数保留各自直接入口。增加 `--tutorial` 可直接进入教程。

v0.1 使用 Godot **4.6 stable** 在 Windows 原生 ANGLE 渲染中查看默认菜单、操作说明与倒悬预览。菜单流程 12 项、教程 58 项、视角旋转 17 项均通过；教程包含 1,517 次位置采样。

v0.2 更换右侧美术后，已在同一本机原生渲染中检查新菜单截图，并重新运行菜单流程 12 项，全部通过。教程及旋转逻辑没有修改，本次没有重复运行其完整检查。

菜单流程检查：

```text
Godot --headless --path game -- --menu-self-test --artifacts=<报告目录>
```

原生截图：

```text
Godot --path game -- --menu-capture=<绝对PNG路径>
Godot --path game -- --menu-world=2 --menu-capture=<绝对PNG路径>
Godot --path game -- --menu-help --menu-capture=<绝对PNG路径>
```

本工作区的本地预览入口在仓库外 `../builds/preview-start-menu.cmd`，依赖同一工作区下 `../tools/godot` 中的引擎；它不是独立发行包。工具、截图、日志和检查报告放在 D 盘。
