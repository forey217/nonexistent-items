# 世界不按说明书 · 启动界面

默认启动进入原生 Godot 菜单。以游戏现有接待大厅为依据，使用观察局内部的档案书柜、木质办公桌、黄铜台灯和蓝色星系仪作为全屏背景。当前 v0.7 使用马善政毛笔字（86px），标题的位置、旋转和大小固定，字面每5.5秒扫过一道暖金流光，带轻微辉光呼吸，不再上下摆动。菜单使用系统黑体，普通24px、选中28px，点击位置保持固定。菜单为“进入观察局 / 选项 / 退出游戏”。背景在 `assets/start_menu/bureau-interior-v4.png`，生成提示词见 `启动界面-v04-图像提示词.txt`。旧版素材保留为历史记录。

动态背景由 `shaders/bureau_title_ambience.gdshader` 在原插画上实时合成：镜头推拉与横移、鼠标视差、星系仪蓝色核心的流动光丝、台灯呼吸光和缓慢扫动的窗边光束。原生绘制层增加三道绕行亮点与拖尾、58枚可见移动的浮尘；星系仪光效位置按实际背景图的蓝色核心校正，并跟随背景镜头移动。家具和黄铜框架没有单独拆层或骨骼动画。所有效果使用菜单显式时间，关闭“动态画面”会冻结标题、背景光效、镜头视差和浮尘，不使用不可暂停的全局 TIME。

毛笔字体来自 Google Fonts 的 Ma Shan Zheng，使用 SIL OFL 1.1，字体、原始许可和来源记录保存在 `assets/fonts/ma_shan_zheng/`；标题仍由原生字体绘制，无需依赖本机安装字体。

## 已接入

- 进入观察局：沿用 v0.24 流程，淡出后进入接待大厅，再点击星系仪进行晶体碎片选关。防止重复点击以及选项面板后的误操作。
- 选项：集中放置声音开关、动态画面开关、世界氛围预览和操作说明，Esc 返回主菜单。
- 冰晶、重力、倒悬预览：在选项中点击或按 1 / 2 / 3，改变背景上的轻微色调、浮光运动与规则说明。预览不会切换整张背景，也不改变关卡初始状态。
- 操作说明：在选项中打开手册，按钮或 Esc 返回选项。覆盖层阻止背景点击及键盘聚焦。
- 动态画面：开关标题浮动、背景推拉与视差、局部光效和浮光；关闭后冻结在当前画面。
- F11：在菜单中切换全屏。
- 返回主界面：大厅和关卡右下角均有可点击按钮，F10 为快捷键。选关、入场和归档过场期间隐藏按钮并阻止返回，避免打断流程；重复请求会被忽略。按钮提示说明重新进入关卡将重置当前关卡。
- 退出游戏：退出当前进程。
- 主菜单键盘：上 / 下移动选中项，Enter 确认；M 沿用跨场景静音状态。

这是本地单机启动菜单，当前没有账号登录、注册、云存档或继续游戏。

## 入口与验证

场景：`scenes/start_menu.tscn`；脚本：`scripts/start_menu.gd`；流程：`scripts/game_flow.gd`。

现有 `--self-test`、`--capture`、`--capture-gait`、`--walk-demo`、`--tutorial-self-test`、`--orbit-self-test`、`--tutorial-demo`、`--hub` 参数保留各自直接入口。增加 `--tutorial` 可直接进入教程。

v0.3 在拉取 v0.24 后改版，菜单流程扩展为 34 项，在 Godot 4.6 stable 的 headless 与 Windows 原生 ANGLE 渲染两种模式下均通过。检查覆盖方向键导航、选项覆盖层、手册返回、静音、动态开关、进入大厅、晶体碎片选关以及从关卡返回菜单。已查看本机实际渲染的主菜单、选项与手册截图。流程仍使用最新 v0.24 的场景切换与共享音频实例。
