# 纸山叠影 · 一键完整过关演示

入口：第二关右上角「观测仪表」→「演示」→「第二关完整演示」。位于「请求提示」之后、「操作说明」之前；不经过确认。第一关不显示此入口。菜单内容超出窗口时可以滚动，键盘焦点会带动滚动。

## 正式演示与真实路线

`paper_demo.gd` 管理独立临时场景和演示生命周期，`paper_demo_route.gd` 只描述生产用路线；菜单没有调用测试脚本。每步调用正式寻路、互动、方向选择、推动、规则切换接口，并检查真实机关状态。演示没有写入完成标记、直接摆放镇纸或瞬移人物。

| 阶段 | 真实操作与等待依据 | 观察重点 |
| --- | --- | --- |
| 旧廊与工具间 | 上层显影，步行取夹，经楼梯下楼 | 规则展开旧廊 |
| 封存架 | 下层倒悬，水纹触顶开架；冰晶落稳 | 先解锁再运输 |
| 接物台 | 水纹推至踏板，重力升台，到位后用夹固定 | 切回冰晶仍保持升起 |
| 山纹下落 | 步行回上层，解除检修撑，重力压开落料板 | 山纹落稳在下层接物区才推进 |
| 水车与吊台 | 山纹进入下层停靠吊台，水纹经分岔到水闸，重力驱动 | 等待真实到层、山纹归属上层与轨道接驳 |
| 木桥与上锚 | 山纹离台到止挡；收夹、显影固定木桥；冰晶过桥、重力锚定 | 上锚锁定后下层保护罩打开 |
| 下锚与双锚 | 下层冰晶卸压，吊台归底且低位通道开放，水纹进井、倒悬上浮 | 最终上层重力、下层倒悬，双锚共同稳定 |
| 归档回程 | 步行上楼走入归位门，正常归档转场，观察局入场 | 在返回观察局后才显示演示完成 |

普通过程约 2.2 倍模拟速度；下落、升降、桥固定和双锚结果约 1.1～1.25 倍。楼梯接近段保留可辨认的正常步行。普通转角连续运输，真实分岔和功能点停车。默认不循环。

镜头以原有范围跟随人物和运输对象，关键升降展示上下层关系；操作前保留原方向箭头及短暂黄铜菱形。任务签读取实际状态，右上角显示简短阶段与「暂停／继续」「退出演示」。完成后提供「再次演示」「返回原进度」。Esc 暂停／继续；M、F11、F10 和窗口操作继续有效。

## 原现场、存档与声音

原关卡实例保留在场景树中，冻结处理、音频、渲染与碰撞，隐藏原界面。演示使用新建的初始第二关、归档转场和临时观察局；退出时恢复原实例的位置、移动路径、正在滑行的镇纸、楼层、镜头、任务、对白及时间倍率。不会用稳定检查点替代即时现场。

游戏流程层在演示期间阻止强制和自动保存、通关计数、游戏时长记录与解锁更新。演示不会调用音量设置保存。暂停同步冻结人物、机关、字幕、语音、镜头和调度；退出清除临时场景、输入与音效尾声，失效异步回调不能创建新场景。

音乐和音效使用原有四路音量。模拟加速不会改变录音音高；对白、字幕采用实际时间。仅保留现有衍月四句短确认：固定接物台、安全接住山纹、山纹回到上层、双锚成立。等待实际语音结束后再交接重要结果，舍弃过期提示，不排队播放完整教学。

遇到不可达位置或实际状态迟迟未成立，最多重新寻路两次；仍失败则暂停，提供重新演示或返回原进度。不会在失败后强制通关。

## 验证

专项入口为 `--paper-demo-check`，可附加 `--demo-repeat-full` 验证连续两轮。测试文件位于 `tests/paper_demo_checks.gd`，与正式控制器分离。隔离目录保存测试记录与音量文件，不接触玩家数据。

覆盖真实运动中启动、初始状态、通关后启动、完整路线与归档回程、连续重播、原现场及磁盘哈希不变、暂停/继续/退出、归档中暂停、异步取消、异常中止、F10 清理、第一关无入口、小窗口菜单滚动、音高与四句确认。

最终 Windows 程序的计时、截图和报告见 `showcase/checks/integration-v0510/paper-demo-check/`；整合验收汇总随导出程序提供。
