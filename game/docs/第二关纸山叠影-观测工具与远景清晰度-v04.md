# 《纸山叠影》v04：远景清晰度与观测工具

日期：2026-10-23。以本轮开始时的实际v03工程为基线，保留双层四规则解谜、关卡解锁、独立存档、机关连续模拟和纸页归档流程。

## 清晰度与坐标

世界视口继续按实际绘制区域及 `get_screen_transform()` 的缩放选取像素尺寸，采用1.25倍渲染，最长边限制3840像素。更新窗口或全屏尺寸时同步调整；静止时不重复分配。鼠标与HUD使用逻辑坐标，`to_render()` / `to_ui()` 对应渲染像素，地面射线和屏幕投影成对转换。

本轮发现四种主要材质虽然设置了mipmap过滤，但导入参数中没有生成mipmap。石板、屋瓦、石墙和木板现在均实际生成mipmap，并启用线性mipmap及各向异性过滤。分别调整纹理重复密度，远景保留较大结构和接缝；保留4× MSAA。没有全局锐化、最近邻滤镜或饱和度提升。

角色独立视口按绘制缩放与近景倍率选择512×640、768×960或1024×1280；同步调整像素尺寸与脚底偏移，保持真实人物比例及落脚点。不会把角色放大假装提高画质。

低于0.85倍率时，山／水镇纸、夹子和吊台使用小型竹纸色识别符号，带克制的墨色轮廓；普通倍率自动收起。父节点和真实楼层共同决定可见性，不透视显示被楼板遮挡的另一层物件。

## HUD与输入

- 左上：小型关卡标题和当前任务；点击定位实际任务对象，H展开观测记录。
- 顶部中央：操作层下拉选择与1—4规则条；持续显示上下两层各自规则、人物所在层及当前操作层。
- 左下：山、水、夹三枚紧凑状态项；镇纸可定位，已取得的夹子可直接召回。具体止挡、机关和通路状态收在悬停信息与记录里。
- 右下：回人物F、提示H、工具。恢复、重开、返回、静音、全屏和退出进入暂停菜单，原快捷键保留。
- 使用墨青半透明底、暖浅灰字、旧铜细线和真实字体。规则按钮及工具不再逐个加厚框；第二关的声音设置也使用墨色面板。其他场景默认选项样式保持原行为。
- 普通提示为短暂小条，相同错误在显示期间不重启计时。剧情通讯使用44像素头像及最多两行正文；较长通讯分页，避免裁掉后文。提示与通讯互斥，无通讯时整体隐藏。

完整记录中包含镇纸所在楼层、实际止挡、夹子、检修撑、落料板、吊台和木桥状态。止挡列表按实际选项数量排布，并主动把镇纸及附近人物放到列表之外的可用区域。

界面空白不截取地图输入；规则条、记录、止挡列表、左下状态、右下工具和暂停层正确拦截点击及滚轮。任务观察与止挡观察会避让遮住目标的屋顶。原有跟随、指向点缩放、手动平移与旋转保留；展开面板时通过安全区域平滑构图。

## 楼梯

沿用并验证真实移动入口：WASD／方向键或左键走入本层入口后自动上下楼。左键点台阶映射为走向本层入口，右键和E不再执行楼梯互动。触发半径0.42地图单位，位于通道内；路过旁边不触发。观察另一层或点击远处台阶不能直接传送。

人物连续改变脚底位置和高度，按上下楼方向保持朝向及正常步态，没有推动动作。局部楼板剖切和屋顶避让保持；两层规则继续模拟。到站清除旧路径、恢复控制，离开0.95单位范围后才能重新触发；入口读档不反复上下楼。中途保存使用最近稳定快照。

自动演示与正式游戏共用点击行走与楼梯触发入口；没有用旧楼梯交互API代替行走。
