# 第一关满构图室内整合 v0.36

第一关采用与接待大厅相同的象牙白石材、深蓝金属、黄铜框架及宇宙舷窗，改为连续室内校准大厅。地面与两面建筑立面延伸到视口之外，移除完整悬浮底座、室外背景圆环和玻璃支架；外围由真实的三维建筑填满，转动视角时保持正确投影。

## 实现

- 新增calibration_interior.gd，复用interior_v30已有的地面、仪器墙及宇宙窗美术，没有新增生成图。原素材来源与完整提示词仍见interior_v30/SOURCE.json；本次设计提示词见“第一关满构图背景与整合提示词-v01.md”。
- 地面连续铺设，细接缝与黄铜嵌线保持低对比度；前侧以低玻璃隔断标明原有可走范围，外侧地面继续延伸。
- 真实三维墙面与高层建筑构件封闭画面。接近极限视角时隐藏几乎侧对镜头的返回立面，避免延伸墙体投影成穿过画面的长条。
- 建筑采用均匀室内照明，关闭高墙的大面积方向阴影；调整主灯与地面颜色，保留设备和人物的接触阴影。
- 镇纸、导轨、挡块、星位踏板、月痕印座、封界踏板与归位门仍为独立实时对象，材质和背景分离。
