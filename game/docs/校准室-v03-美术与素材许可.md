# 新手校准室 v0.3：轨道和房间美术

本次将校准轨道作为视觉中心，替换简易墙面，移除散落纸片、装饰冰晶、书柜和普通办公桌。教程解法、人物步态、碰撞区域、3秒世界折叠CD及通关后返回观察局保持原规则。观察局大厅暂保留上一版美术。

## 已接入的结构与反馈

- 墙面：有厚度的模块墙板、服务管道、铜色护裙、观察窗、窗框与条形灯，统一配色和光照。
- 轨道：深色底槽、24组枕梁及两侧螺栓、金属双轨、连续护边、端部固定架、检修盖、行进箭头和位置指示灯。新增结构全部留在原轨道实体占地内；地面线路和检修盖可正常跨越。
- 压板：分层底座、金属嵌边、固定螺钉、编号与激活灯；第一挡块在释放后回缩并留下插槽。
- 上部接收器：双立柱、横向支撑、齿条、顶部触点、侧方高度标尺与校准记录灯。
- 镇纸：金属包边、角柱、固定螺钉及统一的圆形铜印；仍是同一物品在三个世界采用不同物性。
- 归位门：使用模块门框；屏障、状态灯与导线颜色由实际开门条件驱动。
- 场律电源柜：沿用旧书柜的占地，密封管中的样品在倒悬世界上浮；右键查看当前物理规则。
- 校准监测台：沿用旧桌子的占地，显示挡块、上部记录、末端压力三项状态；右键查看开门条件。两台设备提供信息反馈，不新增解谜步骤。

## 制作方式与后续维护

游戏仍为Godot 2D。原始模型在`tools/bake_calibration.gd`中使用统一的奶白/灰蓝/铜色材质及灯光，从固定正交视角离线渲染为透明PNG；游戏内不运行3D场景。轨道、镇纸、接收器、电源柜、监测台及地板的几何体由该脚本制作，不冒称为下载包自带模型。

固定投影：每个地面网格的两条轴分别为`(46,23)`、`(-46,23)`，原点`(535,222)`；烘焙图为2倍分辨率，游戏中缩放到一半。脚本与原始GLB、贴图和许可都随源工程保留，可以重新渲染，避免只能手动修改一张背景图。

重新生成：在支持实际图形渲染的Godot中运行`--path <game目录> --script res://tools/bake_calibration.gd`，随后让编辑器重新导入PNG。不能用无图形的headless渲染器生成截图。

运行时由`tutorial_map_art.gd`、`tutorial_machine_art.gd`、`calibration_prop.gd`叠加压板、挡块、位置灯、样品、读数、门屏障及高处刻度。它们直接读取教程状态，未改变物理或碰撞。
