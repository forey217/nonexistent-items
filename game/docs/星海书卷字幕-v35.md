# 星海书卷字幕 v0.35

按用户选定的第一款字体方案，将底部无框人物字幕改为清秀宋体风格。

- 字体：Adobe Source Han Serif CN Regular（思源宋体），原始OTF随游戏打包，不依赖玩家电脑是否安装中文宋体。来源和SIL OFL 1.1许可位于assets/fonts/source_han_serif，字体文件未修改。
- 正文：26px，暖白#F5F1E6；字间距增加1px。字体上下留白各微调-1px，额外行距1px，以实际字体行高形成约1.4倍行距，保持底部两行可读且不溢出。
- 姓名：淡金#D8C18D，同款字体，FontVariation运行时轻微加重；姓名与对白一起自然换行，不拆成互相错位的独立标签。
- 描边：从原7px黑色改为1px深墨蓝#173447。阴影向下2px、范围3px、透明度约30%，取消粗黑边的贴纸感。
- 排版：RichTextLabel居中，保留原936×78安全区与字幕位置，最多自然换两行；没有新增字幕框、底板、头像或交互。鼠标穿透、无滚动条、不允许选择文字，继续正常操作。
- 字体修改仅用于无框对白，大框与轻框的排版保持原方案。世界投影、物品展示和机关提示继续随原台词触发。
