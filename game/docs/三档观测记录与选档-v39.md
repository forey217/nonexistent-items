# 三档观测记录与选档 v39

采用已选方案②“扇形档案页”：主界面推近星系仪后，三张象牙纸、黄铜夹档案页沿下半环展开。背景与空白卡片由内置 image_gen 生成，文字、按钮、进度和缩略图由运行时独立绘制；来源和完整提示词见 `assets/save_slots_v39/SOURCE.json`。

## 操作

- 点击档案页选择，再点击该页“建立记录”或“继续观测”。
- 左右方向键或 A/D 选择，回车/空格确认，Esc 或左上角返回取消。
- 悬停时纸页轻抬，选中后显示黄铜描边与深蓝按钮；确认时该页收向星系仪并淡入场景。
- 空档只有确认后才写入，取消不会创建记录。三个档位的剧情、通关次数及时间各自独立。

## 保存与恢复

默认位置为 Godot 的 `user://observatory_saves`，Windows 对应 `%APPDATA%\Godot\app_userdata\世界不按说明书\observatory_saves`。每档 `record_1.json` 至 `record_3.json`，最近使用档位存于 `recent.json`。

保存地点、稳定机关检查点、剧情已读状态、通关次数和累计游玩时间。人物恢复到安全出生位置，机关恢复至最近稳定检查点，滑动、上浮、施法、抵达裂隙及盖章过场不作为中间物理状态保存。

关内检查点依次为：初始状态、到达第一挡块、星位已定、到达导轨末端、月痕已压、界缝已封。机关到位后自动保存；返回主界面、正常退出及完成关卡时也会保存。首次对话完成或跳过才记为已读。

写入经过临时文件、flush、回读和重命名，并保留上一份有效 `.bak`。主记录损坏时尝试有效备份；没有有效备份则显示记录异常并禁用进入，不自动覆盖。较新格式不会由旧版覆盖。

## 验证

专用 `--save-check` 测试覆盖三档隔离、空档创建、取消不落盘、真实机关流程、通关保存、检查点恢复、损坏记录与备份；第二个进程 `--save-check --save-reopen` 验证磁盘持久化。测试必须显式传入隔离的 `--save-dir`，不会污染玩家记录。既有菜单和剧情测试保留旧入口以隔离存档因素。

保留原有三世界解谜、世界切换冷却、轨道互动、NPC 对话、世界教学、选关水晶及通关归档。测试报告与实机截图随试玩包附带。
