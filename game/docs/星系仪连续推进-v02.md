# 启动界面至选档：星系仪连续推进 v02

点击“进入世界观察局”后，标题、按钮和底部文字同步淡出，镜头沿一条缓动曲线向室内插画中的星系仪推近。推进持续1.4秒；到达最终构图后，三张存档卡片、选档标题和返回按钮在0.32秒内原地淡入，不再居中停顿、缩小或上移。

## 连续性实现

- `start_menu.gd` 在转场开始时记录当前画面的缩放、漂移和鼠标视差，冻结背景时钟。镜头从当前已显示的构图出发，不把视差突然归零。
- `bureau_title_ambience.gdshader` 增加固定镜头参数，继续渲染同一幅室内插画；原有无选档测试通路仍沿用原来的镜头参数。
- 镜头按同一个 smoothstep 进度插值可视矩形。最终缩放4.65倍，星系仪中心位于1280×800设计视口的(640,300)，卡片出现后保持不动。可视矩形全程位于原图范围内，避免拉出空白边缘。
- `game_flow.gd` 完成推进后，将实际的背景 TextureRect 交给选档界面。`save_select.gd` 直接重新挂接这个节点，纹理、材质、亮度、缩放与裁切完全沿用；不再载入原来的选档背景，也不再使用 `save_entry_pan.gdshader` 的分段居中和回缩动画。
- 三张卡片保留原有位置、倾角及整卡点击范围，入场只修改透明度。标题增加细描边，保持在明亮背景上的可读性。

## 操作与范围

推进及卡片淡入期间拦截重复进入和提前选档；卡片显示完整后开放选档和返回。M声音与F11全屏继续可用。关闭动态画面时保留当前构图，用0.18秒淡去启动文字，再用0.25秒浮现选档界面，不移动镜头。

返回后重新创建启动界面，恢复初始构图、标题和按钮；再次进入时完整播放推进。保存位置、独立档位、新建、续玩、自动保存及后续大厅和关卡流程保持原行为。

## 运行与验证

运行包：`builds/星系仪连续推进-v02/世界不按说明书.exe`。

实机动画：同目录的 `星系仪连续推进-实机.gif`。动画由原生Godot / ANGLE运行过程逐帧录制，含点击前画面、完整推进及存档卡片淡入。

检查报告：`showcase/checks/save-entry-v02/`。专用 `game/tests/save_entry_checks.gd` 采样真实转场中的镜头参数，检查推进单调性、原图覆盖范围、背景节点与材质交接、卡片淡入期间镜头固定、输入锁定、全屏、不同窗口比例、返回与重复进入，以及三个档位的整卡点击。

现有存档集成检查已按新的连续推进行为更新，继续覆盖独立记录、稳定检查点、重新启动读取、关卡解谜和归档回程。所有检查使用隔离存档目录。

验证结果：专用原生转场28项、菜单79项、存档流程48项、重新启动读取9项全部通过；导出的Windows程序另运行48项存档流程检查，全部通过。原生渲染环境为Godot 4.7.2 / ANGLE，录制90帧、30fps，覆盖点击前到选档界面完整显示。窗口比例及全屏截图与镜头逐帧采样保存在检查目录。
