# 任务追踪界面 v0.7

主任务固定为“校准归位门，返回机构”，黑色。默认仅显示当前一条分任务；其文字为浅黄色，配深灰蓝色底提高可读性。原先常驻的后续校准、压力标记移除。

悬停主任务后，在右侧淡入有序的六个步骤，底部与任务卡对齐；已完成绿色、当前浅黄色、未开始灰色。鼠标可移入列表继续查看，缓慢经过卡片间隙也不会关闭；离开后延迟0.2秒收起。主任务和展开面板拦截点击，避免误下达移动指令。失焦时关闭。

进度依据实际谜题阶段：送到第一压板→加重释放挡块→运到末端→上部校准→末端压力→返回机构。末端压力失效时，对应步骤恢复为当前黄色，不将它错误保留为已完成。R重置清空进度。
