# 方向推动与连续运输 v01

版本为 0.48.1，保存目录名称不变。在当前工作区基础上保留薄玻璃界面、精修物件、通讯联动、环境显影、圆弧轨道、吊台接缝、自动楼梯、旧廊限制及原有解谜流程。

## 玩家操作

右键点山纹或水纹镇纸，出现四枚方向箭头；左键点合法方向，人物会沿真实可达路线走到推动位置，自动面对镇纸并推动。无需提前对准严格角度。附近按 E 同样打开方向选择；键盘焦点可激活按钮。

悬停箭头可见本次真实运输路线及停车点。箭头按当前相机投影指向导轨，保持 50 逻辑像素点击尺寸。无轨道、规则不符、悬浮、通路未开放或人物操作位置不可达时禁用，并用斜线和原因区分。方向控件避让人物、镇纸和主要 HUD，透明间隙不拦截地图。

再次右键同一镇纸、右键空白、左键空白或 Esc 关闭。Esc 不同时打开暂停。WASD、观察层改变、规则改变、暂停、读档和恢复检查点会清理尚未执行的推动，取消后不会稍后补执行。已进入真实滑行后，沿用两层世界切换联锁；重复选择不会排入第二条指令。

## 停靠审查

| 镇纸 / 楼层 | 保留的停车点 | 原因 |
|---|---|---|
| 水纹 / 下层 | cage 封存架 | 真实轨道终点与锁扣机关 |
| 水纹 / 下层 | catch 接物踏板 | 必须稳定受压以抬升接物台 |
| 水纹 / 下层 | guide_turn 导轨分岔 | 玩家选择去水闸还是导向井，不自动解谜 |
| 水纹 / 下层 | sluice 水闸踏板 | 稳定受压驱动水轮与吊台 |
| 水纹 / 下层 | guide 导向井 | 上浮接触高处锚位 |
| 山纹 / 下层 | catch 落料接物区 | 承接真实落料，推送前保留稳定位置 |
| 山纹 / 两层 | lift 运纸吊台 | 装卸和跨层运输，必须对齐停稳 |
| 山纹 / 上层 | anchor 山纹锚座 | 稳定受压完成上层锚位 |
| 山纹 / 上层 | dock 中转台，条件性停车 | 木桥未保留时不能进入缺口；桥合法时连续通过 |
| 山纹 / 下层 | lift_turn，条件性停车 | 吊台缺席或未对齐时，在井口前保留安全边界 |

取消常规停车：水纹的 cage_turn、junction、sluice_turn、guide_bend；山纹下层的 junction、lift_turn，以及上层的 dock、bridge、anchor_turn。条件性边界仍依照上表和实际通行条件停车。没有删除节点 ID，旧存档中的中间位置仍可读入并继续选择合法方向。

典型运输段：

- 封存架 → 封存架转角 → 接物踏板：一次指令。
- 接物踏板 → 普通连接段 → 导轨分岔：一次指令，分岔停下。
- 导轨分岔 → 水闸转角 → 水闸踏板：一次指令。
- 导轨分岔 → 导向井转角 → 导向井：通道开放时一次指令。
- 下层接物区 → 连接段 → 吊台转角 → 吊台：平台停靠时一次指令。
- 上层中转台 → 已保留木桥 → 锚座转角 → 锚座：一次指令。

## 代码与真实规则

`paper_mill_state.gd` 的 `push_route` 为预览和实际移动提供同一个结果：检查实际楼层规则、封存架、木桥、导向井联锁与吊台，再遍历到功能点、分岔或安全边界。圆弧采样读取当前轨道几何的 TURN_RADIUS 与 ARC_STEPS，普通弯道按同一中心线前进。整段只起步和结束一次，中间采样点不减速、不触发到站事件。稳定站点 ID 和存档结构保留。

`paper_mill_room.gd` 负责合法推动位置搜索、普通导航、待执行条件复核和实际推动动作。维持原有近身作用范围，不隔墙、跨层或越过旧廊断口。接物区的坑口属于受支撑的真实接物机关，人物从可达岸边伸手推动，不要求人物踏入不可行走的落料口。

`paper_push_picker.gd` 负责四方向按钮、方向投影、路线预览与局部避让；`paper_mill_hud.gd` 复用现有主题、帮助和输入拦截。原方向依赖的常驻箭头改为执行指令期间的短指向。没有新增止挡列表或远程目的地选择。

`paper_push_driver.gd` 的自动演示改为注入真实右键与左键按钮输入，再等待人物走位和物理移动完成。完整通关不再要求普通转角停靠。

## 教学和配音

更新 8 条受旧推动方式或中间止挡说明影响的提示。通过项目现有 Edge TTS 路径、特斯拉声线 zh-CN-YunyangNeural、-8% 语速及 -4Hz 音高生成对应录音，并保存逐词时间。保留原有 80 条记录及文件，增加本次 8 条教学录音，同时保留当前工作区新增的任务反馈录音，实际清单数量见随包验证报告；新的字幕使用由完整文本计算的新 ID，不覆盖原剧情 ID。新的操作提示不会播放旧的面向推动说明。音频维持单声道 24kHz MP3，做音量归一，不改变逐词时间轴。
