# 第二关导轨结霜 v0.55.0

基于当前包含倒悬实物响应 v0.54.0 的整合工作区，保留主角 271.44 移动速度、圆角导轨、水岸护栏、卷轴归档和轻声脚步。

- 上下层分别维护结霜年龄，首次冰晶入场或从其他规则切回冰晶时播放约 0.90 秒生长。镜头和观察楼层不触发重播。读档直接重建稳定霜层，重新开始重播初始冰晶动画。
- 从真实双轨的直线端点和圆角采样构造独立视觉距离图，分支按连接关系自然扩展，交叉的独立轨网互不连通。薄冰使用实际轨条顶面三角形，略微外扩至 0.13 宽；蓝底、白霜边、低矮冰晶和生长前沿短暂冷雾全部为代码生成。
- 主要结霜 0.90 秒，最晚冷雾约 1.06 秒消失；稳定阶段不循环喷雾或闪烁。离开冰晶后约 0.24 秒退去。低动态选项直接呈现完成状态，无新增声音。
- 霜层按真实可见父节点合批，桥上部分随桥显隐，吊台部分随平台移动，接驳舌只在实际到站时显示；运行中的吊台采用中性轨面，避免中途根据高度跳换规则。
- 世界胶片的旧、新环境分别筛选冰晶霜层，离开冰晶时旧胶片保存当时动画姿态。使用显式时间，不使用 shader TIME，暂停冻结动画；复用有限网格池，不逐帧创建节点。
- 不新增模拟状态、存档字段、碰撞或寻路判断，不改变轨道和机关玩法。

专项测试、圆角/胶片回归、实机各阶段截图和实际运行录屏保存在 showcase/checks/rail-frost-v0550。
