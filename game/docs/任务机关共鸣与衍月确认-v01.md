# 任务机关共鸣与衍月确认 · v01

Windows 独立试玩包：[世界不按说明书.exe](../../builds/任务机关共鸣-v01/世界不按说明书.exe)。本包包含本地当前整合内容，保留已有旧包与固定启动入口。

## 本次行为

- 两关任务完成时，先由刚操作的机关给出局部黄铜扣合、刻线传递及对应材质声音，再由任务签给出小勾和短暂的完成回执。正常回应约 1.5 秒，继续操作不需要等待。
- 第一关在星位、月痕、界缝稳定三个节点确认。第二关替换接物台固定、山纹落稳、山纹回上层、上层锚定、双锚完成的五句衍月对白；不叠加旧句。两句特斯拉后续说明也去掉重复确认并重新配音。
- 新增六句衍月录音与两句特斯拉录音，沿用各自既有音色、速率、音调、对白音量通道及字幕。六类材质短音效使用音效通道。
- 水车、空吊台、人物搭乘只有运行回应，不冒充山纹任务完成。镇纸滑行、下落和未到层时不提前确认抵达；落料板刚打开时保留“安全落到接物区”的目标。
- 新目标立即对应真实状态；完成回执不覆盖新目标、不关闭正在阅读的任务详情。修复鼠标移到任务签后镇纸仍可能保持高亮的问题。
- 确认对白不会抢占 H 提示；过期、失效或重复的观察不排长队。读档先建立基线，不补播历史完成效果；完整重开重置首次记录。
- 机关效果和任务签动画随菜单暂停。原有解谜条件、世界切换限制、吊台乘人、导航和控制锁定规则保留。

实际节点及条件见[制作对应表](../../游戏策划/任务机关共鸣-v01.md)。
