# 星系仪居中后选档

点击“进入观察局”后的顺序调整为：

1. 0—0.9秒：标题和按钮淡去，沿用原插画推近星系仪。
2. 0.9—1.9秒：仪器平稳移动到1280×800视口正中央（640，400），背景边缘柔和衔接，保持暖灯、木色和黄铜。
3. 1.9—2.2秒：居中停留0.3秒，存档标题、按钮和三张档案页保持隐藏。
4. 2.2秒后：先浮现选档文字，三张档案页间隔0.08秒展开；仪器稍微缩回并上移，为卡片留空间。三张卡片展开完成后才接收选档输入，总计约3秒。

关闭动态效果时使用简短静态淡化。M、F11、Esc及存档读取、独立档位、自动保存、关卡与归档流程沿用现有行为。

选档背景先设置忽略纹理最小尺寸，再设置1280×800大小，避免原图尺寸把背景撑大，导致视觉中心与界面中心不一致。

程序：`builds/星系仪居中转场-v01/世界不按说明书.exe`。
截图和检查报告随运行包保存。运行包从本次菜单/存档修改的固定源码副本导出，未包含正在制作的第二关文件。
